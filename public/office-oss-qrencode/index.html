【公众号账号】

入库单、物料码要贴到单据上，很多人的第一反应是打开一个生成网站，复制一行，点一下，保存一张，再复制下一行。单号只有五条的时候，这事儿看起来也能做完；单号一多，人就会在网页和保存对话框之间来回切。

真的只能一张张去网站点吗？这一篇用 qrencode，把单号放进一份文本，一次把码出到文件夹里。先把结果摊开，再倒回去看是怎么做的。

—五张码已经在文件夹里了—

做完以后，「我的文档」里的「入库二维码」不再只有那份列表。五张 PNG 已经排在旁边，每张大约两百多字节。文件名都带上了对应单号，打开文件夹就能对账，不必再回到网页里回忆刚才保存的是哪一条。路径是 /home/laoli/Documents/入库二维码/。材料是自造示例单号，不是真实入库档案。

红框对准五张二维码图，体积约为 281 到 288 字节。上方那份「单号列表.txt」还在，没有被覆盖。

这些图的边长是 232×232。打开其中一张的终端预览，能看到码面，但旁边不会自动写出单号。

红框对准终端里预览的码面，编码内容是 RK-20261127-001。图上只有码，旁边没有自动写出的单号。

工具生成的是二维码图，不会顺手加一行人读文字。把其中一张放大，图上仍然只有码。图说里的单号是后来加上的说明，不是生成时写在码旁的。

这是 示例-RK-20261127-001.png 放大后的样子。左上角的文字是说明标注，不是工具随图打印出来的人读文字。

这篇只写生成，读码是下一步，没有拿去扫描。单号是英数编号，内容已经按生成时写入的字符串核过，和列表一致。先看见结果，再倒回去看列表和命令，会比较有底气。

—倒回去，先看这份单号列表—

开始时文件夹里只有「单号列表.txt」，72 字节。后面所有的码，都从这五行来。

红框对准「单号列表.txt」，大小为 72 字节。当时还没有二维码图。

打开列表，一行一条，一共五条：两条入库单号，两条物料编号，一条单据号。都是英数，没有掺长段中文。命令和证图一致：

cd /home/laoli/Documents/入库二维码
cat 单号列表.txt

红框圈出五条单号：RK-20261127-001、RK-20261127-002、WL-YS-1001、WL-YS-1002、DJ-YS-20261127-01。

【广告位1】

—一条循环，一次出五张图—

参数里，模块大小用 8，纠错级别用 M，输出文件名带上单号，免得事后对不上。默认模块更小，图也会更小；这次选用 8，得到的是 232×232 的 PNG，用来贴单据通常够看。模块大小和纠错级别可以按自己要贴的尺寸再调。这次固定用 8 和 M，是为了五张码尺寸一致，也方便和列表逐张核对。

cd /home/laoli/Documents/入库二维码
while read -r id; do
  qrencode -s 8 -l M -o "示例-${id}.png" "$id"
done < 单号列表.txt

红框对准刚生成的五张 PNG。命令跑完，文件已经写在同一层，不必打开浏览器，也不用一张张点保存。

文件名和列表里的单号对得上，数量也对得上，这一步就算做成了。后面若要贴到单据上并对人读，需要另外排版，不要指望码旁自动出现文字。

—用的时候，有几条边界要记—

能一次出五张图，不等于所有内容、所有用法都已经试过。下面这几条，决定你能把这次结果用到哪一步。

生成的是二维码图，码旁边没有随图打印的单号。要在单据上对人读，需要另外排版。

这次核过的是英数单号。长段中文、带分隔符的混排内容，没有当作已经跑通的结果来写。

这篇没有做扫码交叉验证。生成是这一步，读码另说。

qrencode 是自由开源软件，许可是 LGPL。按官网当前的安装说明安装即可。当前稳定发行已经停了一段时间，不要理解成每周都有新版。

【广告位2】

—我的经验教训—

以前遇到要贴码的单据，我也习惯打开网页一张张点。后来才把单号先写进一份文本，再循环出图。对账的时候，文件名和列表能对上，比在下载文件夹里翻「二维码 (3).png」要稳得多。

还有一处要提前接受：码面本身没有人读文字。文件名带上单号，是为了对得上；若单据上还要给人读，得另外加上，不要指望这一步自动写上。先用英数单号把流程跑通，再决定要不要处理更复杂的内容。生成和读码也分开做，这一篇只保证图已经按单号写出来。

—你今晚就能做的—

  1. 把要出码的单号写成一份文本，一行一条，先从英数编号开始。
  2. 进到这个文件夹，用上面的循环一次出 PNG，文件名带上单号。
  3. 核对这些图的文件名和数量，和列表一致。
  4. 若要贴到单据上并对人读，另外加上单号文字，不要指望码旁自动出现。

—最后—

批量出二维码，不一定要一张张去网站点。单号放进一份文本，一次生成五张 232×232 的 PNG——这是能在自己电脑上当场做完的一步。你要是也卡在一张张点网站出码，不妨先把单号列表写好，在自己电脑上走完这一步。对得上列表，就有底气把码贴到单据上。读码的事，另外再说。
