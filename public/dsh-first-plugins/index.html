【公众号账号】

插件页一打开，列表一长，最容易手滑——「顺便都装上」。装完却说不清装了啥、能不能验，热榜刷过一遍，desktop 里还是一团。

只要装这三个：dshmarket（市场）、dsh-whale-widget（余额小鲸鱼）、dsh-cost-balance（输入框花费条）。装完能当场验收，DeepSeek Harness 今晚就有市场与花费条。

我这边第一脚还翻过：用户级 npm 指着公司源，连续 EAI_AGAIN，三个包全失败。今晚任务不是「装得多」，是「只装三个、装对层、能验收」。

 

—两个常见卡点—

卡点一：一键装满，装完无法验收。市场热榜看着热闹，装了一堆却对不上 package.json，插件页也找不到「装上了」的硬信号。多装不等于办成。

卡点二：公司 npm 源拉失败，却先怪包名。源解析失败时，换包名、重试、再猜镜像——绕一圈还是 DNS/证书问题。对本次安装改走官方 registry，比硬猜包名省事。

先满足这三条再谈第四个插件：能打开 npm/GitHub 源码页、声明了 dsh.bundle、装完有肉眼验收点。

 

—一个方案：首批只装这三个—

选型就一句：一个「找插件」，两个「余额/花费」可肉眼验；都以本机实际能从 npm 拉到为准。路径示例写成 C:\Users\laoli——换成你自己的用户目录即可。

  1. dshmarket——插件市场界面（找插件/逛列表）。
  2. dsh-whale-widget——右下角余额小鲸鱼（余额类看板）。
  3. dsh-cost-balance——输入框下方花费/余额条。

记住这个：第三方插件与 DSH 同机运行，权限接近宿主。这不是浏览器扩展。装前看源码页，不装来路不明、只给一句命令的包。

【广告位1】

 

—第一步：退出桌面版，再对 desktop 执行 add—

不退出，desktop profile 可能被锁。完全退出 DeepSeek Harness（托盘也退出），再用桌面自带 dsh.cmd，指定 --profile desktop。

dsh plugin --profile desktop add dshmarket
dsh plugin --profile desktop add dsh-whale-widget
dsh plugin --profile desktop add dsh-cost-balance

我这边用户级 npm 源指向公司仓库时，三条全挂在 EAI_AGAIN。对本次安装改用官方 registry.npmjs.org 后再跑——三条都 Done。版本以你拉到的为准，正文不写死「必须」某一号。

图：三条 add 均 Done。公司源失败时改官方 registry 再装——真测边界，不是装前失败屏伪造。

 

—第二步：装前风险——只装能打开源码页的包—

默认建议：只装 npm 上能打开页面、有 README、声明了 dsh.bundle 的包。GitHub 源码安装可能跑构建脚本——今晚首批优先 npm 预构建包。

  • 能打开 npm / GitHub 页，才继续 add——为什么：同机权限，装前要看得见来路。
  • 不装「来路不明、只给一句命令」的包——为什么：没有 README 就等于盲装。
  • 想加第四个，先读它的 README 风险段——为什么：到这里可以停，少装比装多更安全。

不要为了省事关掉脑子一键装满市场热榜。热榜不等于可验收清单。

 

—第三步：验收 package.json 与「插件市场」页签—

验收一：打开 desktop 的 package.json，dependencies 与 bundles 里都出现这三个包。

图：验收点——dshmarket / dsh-whale-widget / dsh-cost-balance 都在。

验收二：重新打开桌面版，进插件页。出现「插件市场」页签——这是 dshmarket 生效的强信号。和内置插件配置抽屉不是同一处，别看错层。

图：红框对准「插件市场」页签——装上 dshmarket 后应能看到。

图：内置四项可配置；与「插件市场」页签不是同一抽屉，第三方能力以你本机界面为准继续点验。

验收一句：命令行刷过屏不算办成；package.json 有三依赖 + 插件页有「插件市场」页签，才算今晚装上了。鲸鱼气泡或花费条若暂时没数字，先查 DeepSeek 凭据，再谈卸装。

【广告位2】

 

—容易漏的边界—

  1. 装到 web profile。桌面看不见——层装错了。desktop 插件要退出桌面后再改 desktop profile。
  2. 公司 npm 源 DNS/证书问题。换官方源或可用镜像，不要硬猜包名。
  3. 余额类插件没数字。要有可用的 DeepSeek 凭据才会显示；没数字先查 Key，不先卸插件。

停止条件说清：源都拉不下来，就不要继续堆第四个包；package.json 对不上，就不要急着说「插件坏了」——多半是装错层或没退出桌面。如果你只是今晚想逛市场、看余额条——三个够了，到这里可以停。

如果你是「先把环境跑通、再慢慢挑插件」——就按上面三条走。如果你是「要上生产、要过安全审计」——第三方同机权限这一条，先过你们自己的白名单，再谈 add。

 

—最后—

意图就一句：只要装这三个，DeepSeek Harness 今晚就有市场与花费条——能找插件、能瞟余额、能看到花费条。不是装得越多越好，是装得可验收。

边界也一句：它帮你把首批插件钉在 desktop 层并给出验收点；它不替你保证余额数字一定立刻出来，也不鼓励一键装满热榜。公司源失败就改官方源再装——这条真测过，照着排查就行。

少装、装对层、能验收。比「装得多」更重要。下期见。
