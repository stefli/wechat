正文

打开插件市场的瞬间最容易手滑：列表一长，就想「顺便都装上」。

今晚任务：只装 3 个能当场验收的插件——市场、余额小鲸鱼、输入框花费条——并写清风险。

它会不会在安装这一步就翻车？我本机第一脚就翻过：公司 npm 源解析失败。

- - -

先把原表摊开：今晚只装谁

  1. dshmarket——插件市场界面（找插件/逛列表）。
  2. dsh-whale-widget——右下角余额小鲸鱼（余额类看板）。
  3. dsh-cost-balance——输入框下方花费/余额条。

选型理由：一个「找插件」，两个「余额/花费」可肉眼验；都以本机实际能从 npm 拉到为准。

乱装的问题，现场就会碰到

第一步：退出桌面版。不退出，desktop profile 可能被锁。

第二步：对 desktop 执行 add。我这边用户级 npm 源指向公司仓库，连续 EAI_AGAIN，三个包全失败。

第三步：改走官方 npm registry 再装——三条都成功，耗时大约数秒到半分钟级。

现场：三条 add 均 Done；版本以你拉到的为准，不必写死。

【广告位1】

装前看源码页，风险先说清

第三方插件与 DSH 同机运行，权限接近宿主：能碰你选中的工作区文件。这不是浏览器扩展。

  • 只装 npm 上能打开页面、有 README、声明了 dsh.bundle 的包。
  • GitHub 源码安装可能跑构建脚本——今晚首批优先 npm 预构建包。
  • 不装「来路不明、只给一句命令」的包。

不要为了省事关掉脑子一键装满市场热榜。

正确安装姿势（桌面版）

  1. 完全退出 DeepSeek Harness（托盘退出）。
  2. 用桌面自带 dsh.cmd，指定 --profile desktop。
  3. 若公司源失败，对本次安装改用官方 registry 再执行 add。
  4. 重新打开桌面版，进插件页验收。
dsh plugin --profile desktop add dshmarket
dsh plugin --profile desktop add dsh-whale-widget
dsh plugin --profile desktop add dsh-cost-balance

验收：核对这两处

核对 package.json：dependencies 里出现三个包，bundles 列表也带上它们。

验收点：dshmarket / dsh-whale-widget / dsh-cost-balance 都在。

核对界面：插件页出现「插件市场」页签——这是市场插件生效的强信号。

红框：插件市场——装上 dshmarket 后应能看到。

已安装列表与内置配置；第三方能力以你本机界面为准继续点验。

【广告位2】

验收过这两处，你才有资格说「今晚装上了」，而不是「命令行刷过屏」。界面上鲸鱼气泡或花费条若暂时没数字，先查 Key，再谈卸装。

坑位速记

  • 装到 web profile：桌面看不见——回去看上一篇三层心智。
  • 公司 npm 源 DNS/证书问题：换官方源或镜像，不要硬猜包名。
  • 余额类插件要有可用的 DeepSeek 凭据才会显示数字；没数字先查 Key，不先卸插件。

你今晚就能做的

  1. 退出桌面版，只 add 上面三个包。
  2. 打开 package.json 核对依赖。
  3. 打开插件页，确认「插件市场」页签。
  4. 到此可以停；想加第四个，先读它的 README 风险段。

现场记一句：少装、装对层、能验收。比「装得多」更重要。
