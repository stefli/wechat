【公众号账号】

想把 DeepSeek Harness（简称 DSH）桌面版装通，却卡在三处：开始菜单找不到入口、模型 Key 不知道往哪填、工作区路径一脸懵。不是软件坏了，是这三件事还没按顺序钉死。

只要按这三步：打开入口 → 配好 Key → 建好独立工作区，再发一句最小问题，桌面版就能跑通第一句。今晚任务就这一件——装通，不折腾插件。

先别急着点侧栏里的「插件」。打开主界面，对一下侧栏有没有「新会话」和「默认工作区」——这两处认清了，后面步骤才走得稳。

 

—三个常见卡点—

卡点一：找不到入口。装完只记得下了安装包，桌面快捷方式不一定显眼。开始菜单搜「DeepSeek Harness」才打开；关窗不等于退出——托盘里可能还在跑。

卡点二：Key。欢迎页或设置里要走官方 API Key / 账号。Key 只进本机凭据，不要贴进聊天、截图、笔记外传。

卡点三：工作区。没选文件夹就开干，Agent 不知道读写边界；直接点进你正在写的工程更糟——先建独立示例夹再选。

问题往往不在「会不会聊」，而在入口、Key、工作区有没有按顺序就位。

红框：侧栏「新会话」与「默认工作区」——今晚先认这两个入口。

【广告位1】

 

—一个方案：三步钉死，再发第一句—

思路很简单：先把桌面壳打开并认入口，再把 Key 配进本机凭据，再用独立示例夹当工作区，最后新会话发一句最小问题。插件市场今晚可以看，但先别装——装通是今晚的验收线。

材料放哪：示例目录写成 C:\Users\laoli\Documents\dsh-demo-install-first-run——你本机换成自己的用户目录即可。别占用正在写的工程。

 

—第一步：打开桌面版，认入口—

打开…开始菜单搜 DeepSeek Harness，等到主界面侧栏出现「新会话」。核对…左侧还能看到插件、工作区相关入口；中间是对话区，底部是输入框。配置与会话落在用户目录下的 .dsh，工作区则是你自己选的文件夹。

关窗不等于退出。Windows 托盘里若还挂着图标，后续要改插件前得先退出 DeepSeek Harness，别只关窗口。

 

—第二步：配好 Key，别写进会话—

粘上…按欢迎页或设置走完官方 Key / 账号，保存后再谈工作区。硬规矩：Key 只进本机凭据；截图设置页前先遮住；正文永远不写真实 Key。

Key 无效或欢迎页过不去——先停。修好凭据再往下，别一边报错一边建工作区。

 

—第三步：建独立工作区—

先在「我的文档」建示例夹，再在桌面版里选为工作区。路径示例：

C:\Users\laoli\Documents\dsh-demo-install-first-run

核对…工作区名称出现在输入框附近的「默认工作区」一带，说明边界已经圈上。选错到别人的工程？立刻改回示例夹，再继续。

 

—验收：新会话发第一句—

点「新会话」，在底部输入框发一句最小问题。我用的验收句是：

用一句话介绍 DeepSeek Harness

红框：底部输入框与「默认工作区 / 标准模式」——第一句从这里发。

本机实测里，桌面 UI 的输入框用自动化键入不稳定；我改用同一套桌面版自带的命令行，在示例目录跑 headless 做并行验收：

dsh --profile headless "用一句话介绍 DeepSeek Harness"

命令正常退出、stdout 给出一句中文介绍——第一句算跑通。桌面聊天框你今晚手动点一下发送即可，路径与验收标准相同。（不在这里剧透具体退出码；你本机以「有一句可读回复」为准。）

同一晚验收：示例目录下 headless 跑通一句中文介绍并退出。

红框：装通后侧栏能进「插件」页——下一篇再讲别装乱。

【广告位2】

 

—容易漏的边界—

  • 关窗≠退出：托盘可能还在跑；装插件前要退出应用。
  • Key 进截图：设置页有 Key 时先遮住再拍。
  • 占用当前工程：先建示例夹，再选为工作区。
  • 版本号执念：跟着当前桌面版走即可，不必死盯某个小版本号。

停止条件：欢迎页过不去、Key 无效、或工作区无权写入——先停，修好再谈插件。能做的是把入口、Key、工作区钉死并跑通第一句；不能做的是指望没配 Key 也能稳定验收。

装通之后侧栏能点进「插件」页，不代表今晚就要装插件。下一篇专门讲 profile / plugin / Web 三层，避免手痒乱装。

 

—最后—

写到这里，把意图再说清楚：DeepSeek Harness 桌面版今晚的目标是装通——入口找得到、Key 进本机、工作区有边界、第一句能回。它不是又一个网页聊天框，而是让 Agent 在你本机目录里干活的壳；但壳要先立住，再谈插件与换模型。

边界就一句：三步按顺序走完，验收看「有一句可读回复」；不保证某个模型更聪明，也不把插件市场当成今晚必做项。入口、Key、工作区这三处守住，装通就不容易翻车。

今晚把桌面版装通就行。下期见。
