正文

群里有人甩了一句：「马斯克刚转发 Grok Bot 新功能，你还不去看？」我点开一看，mattyp 那条 What’s New 片，章节密密麻麻——Pages、Vault、1Password、Apple、出片、角色、Spaces……

我是老李。提速、新卡片那套我另说过，今晚不复读。就按片里顺序，一项项点开：哪些普通人今晚能上手，哪些还得等授权、等设备。

问题来了：转发很热闹，真动手时会不会踩空？下面按时间线走，翻车也写。

 

—先把路线图摊开—

我不跟风复盘整条片。片是 mattyp 拍的，我负责跟做。顺序就跟章节表走：Pages → Vault → 1Password → Apple → 出片 → 角色 → Spaces，Font／Design／Rapid fire 收成一段顺带。

自制信息图：按 mattyp 章节顺序的今晚试跑路线

你要是也想跟，别一上来就堆权限。先拿一个清单页热手，密钥类往后放——省得聊着聊着把密码贴进对话框。

 

—Pages：先落一页清单—

片里演示的是：跟 Sales Analyst 说一声，生成看板，还能挂「每周一更新」。我这边没装销售戏，就干一件更实在的事——把今晚要试的功能做成一页清单。

我当时就这么跟它说的：

帮我做一页「Grok Bot 新功能试跑清单」。
按顺序列：Pages / Vault / 1Password / Apple / 出片 / 角色 / Spaces。
每条留一格「结论」，先空着，我试完再填。
分享先保持私密。

结果呢？页建出来了，Library 里能看见。片里说的例行更新（比如每周一刷新）我没在本页强行挂上——清单用途不同，别硬套演示剧本。

所以你下次可以：凡是要回看的看板、试跑表、周报骨架，直接说「做成一页 Page」。私密默认先开着，确认内容再谈分享。

这一步热完手，后面才进密钥、手机权限那些更敏感的项。别一上来就挑战自动填密。

【广告位1】

 

—Vault：空仓也是一手结论—

片里强调一句很硬：密钥不给 Bot 看，只在目标站填。界面是保险箱分区——登录、卡、联系人——外加加密保存的提示。

我打开本账号的 Vault list。你猜怎么着？空的。没有已存联系人，没有卡，没有登录项。

这就尴尬了吗？不尴尬。空仓说明我还没往里存，也说明今晚测不了「自动填密跑通」——别硬吹。

示意卡：密钥不进聊天、只填目标站（非真实保险箱截屏）

红线就一句：密码、卡号别直接贴进聊天。走安全表单进 Vault，让 Bot 在目标页填写——这是片里的设计意图，也是你该养成的手感。

 

—1Password：片里没演完，我这边也没接上—

mattyp 对着镜头说：正在和 1Password 合作，想让智能体集成更好。完整 UI？片里没有。我就老实写：口述有，演示无。

本账号查了一下凭证提供方状态——未连接任何密码管理器。提示还是走安全表单／Vault。

所以你今晚别指望「接上 1Password 就自动过登录」。合作在推进，不等于你账号已经能用。先把 Vault 习惯养好，更稳。

 

—Apple：权限在手机上，我没擅改你的日历—

片里 iPhone 一串开关：Home、提醒、定位、通讯录、时钟、日历。语音示例很生活：「六点提醒我给妈妈打电话，顺便把客厅灯关了。」

我这边呢？工具列表里能看到手机日历、闹钟、定位相关能力。但没擅自写你的日历，也没偷设闹钟——这种事得你点名。

HomeKit 关灯？我这台环境没有可验的 Home 设备，关灯这一项今晚验不了。有 iPhone 的朋友：先在手机上把权限一条条打开，再拿语音小任务试；别听片就以为全平台都通了。

 

—出片：短样成了，别当成成片流水线—

片里 Studio 机器人出宇航员走火星的短片，挺唬人。我没复刻整条工作室流程，只验证一件事：文本出片能不能落盘。

提示词我写得很画面：

生成一段约 6 秒、16:9 的短视频：
宇航员走在火星地表，阳光从侧面打过来，
尘土轻微扬起，电影感，真实感优先，不要字幕。

结果呢？短样出来了——大约 6 秒、16:9，静帧能看清宇航员和地表。这就够证明：能出短片样。

一手短样静帧：GenerateVideo 文本出片成功；≠ Remotion／成片剪辑流水线

不足也得直说。这不等于标题包装、BGM、封面、多机位剪辑那一套成片流水线。你要发视频号长内容，还得另接剪辑工具；短样只适合验证画面和情绪。

所以你下次可以：先用一句话把镜头说清楚（景别、光线、时长、画幅），再让 Bot 出短样；满意了再谈后期。

 

—角色：换皮好玩，队友更管用—

片里有南瓜、爱心那些季节头像，看着热闹。我账号这边早就有多名专职队友 Bot——成片评审、新闻捕手、科技热点简报这类。

头像换皮是 UI 糖。真提效的，是把重复活交给固定角色，别每次从零人设。你要是只有一个万能聊天窗，今晚可以先开一个「只干清单／只干检索」的窄角色试试手。

 

—Spaces：搜得到 live，我就听，不办场—

片里问「现在有什么热闹 Spaces」，直接甩出听众数列表。我跟做时搜了关键词 AI，状态不限。

当时就这么问的：

现在有什么值得听的 AI 相关 Spaces？
列出正在 live 的几条，带大概听众规模，我只听不办场。

返回里确实有多条 live，比如带 AI 字样的闲聊场，听众能到三位数量级。前提是：你的 X 插件得先连上。连不上就别怪 Bot「找不到场」。

我只搜、只听。办场、上麦那是另一档权限与风险，今晚不碰。

 

—Font／Design／Rapid fire：顺带一眼—

这三截我按「目检」处理，不抢主线。手机字体刷新、桌面右栏 Library／详情、Slack 重连卡片、并行 Helper、邮件转发版式……每一项都像抛光，不是今晚必须跟做的核心。

你要是界面已经顺手，可以跳过。卡在右栏找不到历史页、或 Slack 老掉线，再回头对片里这两段。

【广告位2】

 

—翻车与边界，摊开说—

1Password 今晚接不上。片里无完整 UI，本账号未连接——别被「正在合作」四个字带飞。

Apple Home 关灯未验。没设备就老实说验不了；有 iPhone 也得先授权。

Vault 空仓。不等于功能坏了；等于你还没存。存之前，别把密钥贴进聊天。

出片≠成片。6 秒样片能交差验证，交差发布还得剪辑链路。

另提一句：提速、新卡片 UI 我另文写过。本篇是名人钩子下的功能清单跟做，两篇别混成一篇复读。

 

—你今晚就能做的—

1. 丢一句「做成一页 Page」，把要试的功能列成清单，私密保存。
2. 密码／卡号走 Vault 安全表单；1Password 没接就先别赌自动填。
3. 想听场：问「现在有什么值得听的 Spaces」；想看画面：用一段写清镜头的提示词出短样。
4. 有 iPhone 再开提醒／日历权限；没 Home 设备别硬测关灯。
5. 不适合硬刚的信号：非要今晚打通 1Password、或把短样当正式片发——停，改目标。

自制清单：适合今晚就试 vs 先停一停

敢动手，是因为步骤短、材料普通；不被忽悠，是因为空仓、未连接、未验关灯我都写了。马斯克转发只是钩子——手感得你自己点出来。
