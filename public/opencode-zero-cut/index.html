【公众号账号】

群里有人甩一句：OpenCode 挂上 Editor V1，整支视频能 $0 剪完。听着很香——问题是那份 Editor V1 zip 在 Skool（nextphase）里，我这边进不去原版包。

今晚不绕弯：用公开可复现的替代技能 open-editor-lite，配 OpenCode 里还挂着的免费模型，把一段 30 秒毛片剪成能交差的短片。先说清楚边界——

本篇实测不是原版 Editor V1。原版在 Skool 发放；下面所有步骤、命令、截图，跟的都是公开替代路径。它能不能在你机器上跑通？按时间线往下点。

· · ·

— 先把材料摆齐 —

独立测试工程放在：

/home/laoli/projects/laoli-demo-opencode-zero-cut/
  raw/rough-30s.mp4          # 示例毛片约 30 秒
  open-editor-lite/          # 公开技能（SKILL.md + scripts）
  out/                       # 成片输出

毛片结构故意做了「中间一段 DEAD AIR」：前 8 秒有内容、中间 12 秒废片、后 10 秒再有内容。剪辑目标就是裁掉废片、加 2 秒片头字卡、烧一行底字幕。

本机还要备好：

  • OpenCode 当前版（我这边是能跑 opencode models 的客户端）
  • 本机 ffmpeg / ffprobe（算力自备，不算进云账单）
  • 免费模型仍在列表里：至少看见 opencode/glm-5.3-flash-free

图1 · 免费档还在不在，先看 models

【广告位1】

— 第1步：挂上公开剪辑技能 —

打开技能目录，把 open-editor-lite 链进去。注意：不要假装自己装了 Skool 的 Editor V1——名字都对不上，后面出问题也没法对照。

mkdir -p ~/.config/opencode/skills
ln -sfn /home/laoli/projects/laoli-demo-opencode-zero-cut/open-editor-lite \
  ~/.config/opencode/skills/open-editor-lite
ls -la ~/.config/opencode/skills/

技能里有完整 SKILL.md，脚本包括：cut.sh、concat.sh、titlecard.sh、burn_text.sh、一键 pipeline_demo.sh。触发句就一句：

用 open-editor-lite 剪这段视频

图2 · skills 目录里挂上的是 open-editor-lite

— 第2步：指定免费模型开跑 —

进工程目录，用 OpenCode 跑会话。模型钉死免费档，权限用自动批准（本机可信工程）：

cd /home/laoli/projects/laoli-demo-opencode-zero-cut

opencode run --auto --format json \
  --model opencode/glm-5.3-flash-free \
  --title "open-editor-lite-zero-cut" \
  "用 open-editor-lite 剪这段视频。
工作目录就是当前目录。
原片：raw/rough-30s.mp4（约30秒，中间有 DEAD AIR）。
请按 open-editor-lite 技能执行：
1) ffprobe 探片
2) 跑 scripts/pipeline_demo.sh .
3) 验收：回报原时长→新时长、输出路径、跑过的命令
必须真实执行 shell，不要编造成片。"

$0 的含义先钉死：没有 Claude / ChatGPT 订阅、也没往自己的 API Key 里烧钱；账单侧是 OpenCode 客户端里的限时免费模型。ffmpeg 吃的是你本机 CPU，不算云账单，但电和机器是你自己的。

— 第3步：看它有没有真动刀 —

会话起来以后，模型会读技能、探片、调 pipeline_demo.sh。我这边墙钟大约 31 秒 跑完；JSON 日志里五次 step_finish 的 cost 全是 0，合计 $0.00。

图3 · 会话 cost 证据

终端侧能看见流水线依次：裁 0–8 秒 → 裁 20–30 秒 → 生成 2 秒片头 → 拼接 → 烧字幕 → DONE out/final.mp4。

图4 · pipeline 终端输出

— 第4步：对照成片验收 —

最关心的时长对上了。原片 30.02 秒 → 成片 20.12 秒；中间 DEAD AIR 没了，开头多了青色字卡「ZERO CUT DEMO」，底字幕写着 open-editor-lite / not Editor V1——故意留着这行，防止有人把这篇误传成「原版 Editor V1 实测」。

验收清单（你可以照抄勾）：

  • 成片存在且可播
  • 时长短于原片（去冗余任务）
  • 分辨率与原片一致（本例 1280×720）
  • 字卡 / 字幕文案与提示词一致
  • 会话 cost 为 0（或你账上确认无 Key 扣费）

【广告位2】

— 我的经验教训 —

我当时差点被「Editor V1」四个字带跑——以为没有 Skool 包就测不了。后来发现：读者要的是能复现的剪辑路径，不是某社区 zip 的名字。公开技能写清楚触发句和验收清单，反而更好跟。

另一件：免费档限时，而且必须在 OpenCode 客户端里头用。你要是拿裸 API 去撞，常见会直接被墙；别把「客户端内 $0」理解成「全世界随便 curl」。

还有：短片这条链路能跑通，不等于长片、多轨复杂动效、精细逐句时间轴字幕都能同一套 $0 搞定。open-editor-lite 定位是最小公开替代，不是把剪映 / 专业 NLE 一口吞掉。

— 最后 —

结论钉三句：

  1. 本篇不是原版 Editor V1 实测；原版在 Skool（nextphase），本篇公开技能叫 open-editor-lite。
  2. OpenCode + glm-5.3-flash-free + 该技能，我这边把 30 秒毛片剪到约 20 秒，会话 cost=$0.00。
  3. $0 只覆盖「客户端内限时免费模型」；本机 ffmpeg 自备；免费档随时可能收档——别把限时促销写成永久承诺。

想少被名词忽悠：先看技能是不是公开可跟，再看会话 cost 是不是真的 0，最后才谈「整支视频」四个字能不能吹到你的片长。
