【公众号账号】

三家报价摊在桌上：一家含税，一家未税，一家还写着包邮。肉眼 供应商比价 最容易栽在「裸比大小」——未税 0.42 看起来更便宜，乘完税未必。

今晚只办一件：打开 DeepSeek Harness 桌面版，把三份报价并成比价一览，并把必须人核的行标出来。谁「价格最优」可以后说，先把口径摊平。

跟做路径同样是桌面：材料放齐 → 新会话 → 粘提示词 → 验收未税与运费是否分清。

 

—三份报价放桌面—

华东紧固件含税 0.45、华南某五金未税 0.42、宁波标准件含税 0.50；交期、MOQ、运费各写各的。材料放在桌面 三家报价。先别急着比谁便宜。

关键是字段齐：单价、含税口径、交期、MOQ、运费、有效期。读者侧可换成自己的 PDF 导出文本，流程一样。

  1. 三家同一品名规格，避免比错料
  2. 含税／未税必须原样保留
  3. 运费单独成字段，禁止揉进单价

红框：桌面「三家报价」三份文件。

【广告位1】

 

—桌面里怎么点—

打开 DSH 桌面版 → 新会话 → 说明材料在桌面「三家报价」→ 粘贴提示词 → 发送。

请读取桌面上的「三家报价」文件夹里的三份报价文本。

任务：并成一张「比价一览」。
列：供应商｜品名｜单价｜交期｜付款条件｜备注
再给一小节：同品名最低单价是谁、交期最短是谁、付款条件最宽松是谁。
数字只许引用原文，禁止编造。用 Markdown 表格直接回复在对话里。不要改原始文件。

含税与未税禁止裸比大小；运费单独说明。

红框：桌面主区——比价提示词已粘贴。

 

—比价一览怎么读—

三家都进表了。华南未税 0.42 不能直接跟含税 0.45／0.50 比大小；交期最短是宁波 5 个工作日；付款条件三份原文都没写清——模型老实写了「无法判定」。

红框：桌面主区比价表与「谁最优」小结——未税行要人核。

所以你下次可以：先看口径是否一致，再谈谁便宜。供应链老登视角：比价表是谈判备忘的附件，不是合同。未税行没人核，就别在群里甩「这家最便宜」。

桌面会话帮你把三家字段摊开；下单前的样品、账期、有效期，还是人核。

【广告位2】

 

—坑与何时停—

折算后写「价格最优」可以当草稿观点，不能当下单依据。有效期、运费区间、加急加价都要人核。

  • 未税与含税仍裸比 → 打回重出
  • 运费进了单价 → 打回，分列
  • 有效期已过 → 表可留，下单前重询

 

—最后—

供应商比价这条，DSH 桌面适合并表与标人核；不适合替代采购决策。AI办公：报价进桌面 → 一览出 → 人核未税与运费。

DeepSeek Harness 帮你把三家口径摊平，你再决定谈哪一家。办公Agent 到这里就该停，后面是邮件、样品、合同。

你今晚跟做只抓一句：禁止裸比，未税必人核——比价一览才有资格进采购群。
