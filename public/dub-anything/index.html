正文

周末陪孩子看一部日本动画，英文配音版一开口，我就出戏了：声音是好听，可跟原来那个角色完全不是一个人。字幕版又得盯着屏幕下方，眼睛累。

那天我在 GitHub（全球最大的代码托管平台）上刷到一个刚冒头的开源项目，叫

dub-anything。它想干的事很直接：把片子配成另一种语言，但声音还是原演员自己的。音乐、音效、笑声原样留着，只把台词换掉。

— 它到底是个啥 —

一句话：一套在你自己电脑上跑的配音流水线，外加一个“AI 导演”。

你扔给它一个视频，它还你一个同名的

(dubbed).mkv 文件：默认播放配音版，原声是另一条音轨，切一下就回去了，双语字幕也一起塞进去。视频和音频不出你的电脑，模型都在本地跑，联网只为下载模型。

它不是一个点一下就出结果的软件。官方的玩法是：用 Claude Code、Codex、Cursor 这类 AI 编程助手打开项目文件夹，跟它说一句：

Dub D:\movies\my-show.mkv into English.

然后 AI 助手照着项目里的说明书，一句一句地“导”这部片子。

— 流程拆开看，难点都在第5、6步 —

README 里的工作流程（终端截图，红框为老李标注）

它的流程大概是这样：

1. 按说话停顿把视频切成 3 分钟左右一段；
2. 把人声和背景音乐、音效分开；
3. 用 Whisper（开源语音识别模型）听写台词，再请两个识别器当“第二意见”，画面里烧进去的字幕也拿来对照；
4. 比对声音和画面，认出每句话是谁说的；
5. AI 导演出场：改错字、翻译，并且按演员原来那句话的长短来写译文；
6. 用演员自己的声音念新台词；
7. 卡时长、混音、回听检查；
8. 装回原视频，不重新压缩画面。

我觉得最聪明的是两处：

一是“演员这句怎么说，克隆就怎么说”。一般的工具只拿演员一小段声音做克隆，整部片子都用这一份。它是拿演员这一句的原声去提示克隆，所以吼的还是吼，嘀咕的还是嘀咕，情绪不容易丢。

二是“先算时长，再写翻译”。很多配音工具的做法是：译文念长了就硬加速，听着像快进。它是先预估每句能念多久，让 AI 按这个长度去写译文，最后再把每句收尾对到演员闭嘴的那一刻。这跟口型完全对齐还不是一回事，但起止时间对得上，看起来就顺很多。

另外它每句渲染完都会再“听写”一遍，念糊了就重来，最多三轮挑最好的。拿不准是谁说的台词，它会直接告诉你“这句是我猜的”，不藏着。这点我很喜欢，做系统的人都知道，敢标出不确定的地方，比假装全对靠谱得多。

— 先泼盆冷水：门槛不低 —

官方写的硬件要求（终端截图，红框为老李标注）

官方写得很清楚：

• Windows 电脑 + NVIDIA 显卡，显存至少 6G，16G 的卡能全部同时跑；
• 硬盘大约 40G 放模型和环境，干活时还要更多，作者说配一整部电影两种声音，中间一度占了 85G；
• 速度：一部电影两种声音，在笔记本 4090 上大约要 7 个小时，只配原演员声音大概一半；
• 还得装一个叫 VoiceStudio 的开源语音引擎，项目只是指挥它干活。

Linux 和 Mac 呢？作者说 Linux 加 N 卡应该“改一点就能跑”，没显卡大多能退回用 CPU 跑，但会慢很多。我手边这台用来折腾的 Linux 机器没有独立显卡，内存也就 16G，照这个配置单，跑一部片子基本是看着进度条过周末。所以想上手的朋友，先看看自己的显卡再说。

装法本身倒不复杂，核心就三件事：

# GitHub 搜 swax/dub-anything，克隆到本地
winget install Git.Git astral-sh.uv Gyan.FFmpeg
# 再按 docs/setup.md 装好 VoiceStudio 和模型

— 中文用户最关心的：能配成中文吗 —

代码里目前支持的语言组合（终端截图，红框为老李标注）

现在还不能。目前跑通的组合是：日语、西班牙语、韩语、中文 → 英语，以及英语 → 日语、西班牙语。中文只在“被翻成英文”这一边。

不过作者的思路挺有意思：缺哪种语言，就让你的 AI 助手现场补一个。每种语言要补的东西放在一个文件里，比如 Whisper 在这种语言里爱瞎编的话、拿什么当第二意见、怎么比对念得对不对。补好了先拿短片试一遍，再提交回项目。换句话说，英文→中文这条路，等着有人走一遍。

— 老李的判断 —

说说我的看法，优点缺点都直说。

值得看的地方：它没有再造一个模型，而是把一堆现成的开源工具（分离人声、识别、克隆、混音）串起来，再让 AI 助手当导演，把“判断”这件事交给会读说明书的 AI。这个分工思路，跟我们做供应链系统很像：机器干重复活，关键节点留人拍板。而且它明说“AI 听不见，你来当耳朵”，表演、音色、混音好不好，最后是人说了算。

要掂量的地方：一是硬件，没有像样的 N 卡就别硬上；二是项目很新，九月底才有第一次提交，现在星星个位数，坑肯定不少；三是版权和授权，作者自己也强调了，只配你有权使用的片子，克隆别人的声音要有对方同意，别人的电影配出来只适合自己看；四是有几个模型的许可证不允许商用，想拿来接活的先挨个查清楚。

适合谁：手里有 N 卡、爱看日韩剧或动画、又受不了“陌生人配音”的朋友；还有想研究“AI 怎么当导演”的开发者。只想一键出片的，先等等，或者继续用在线服务。

— 一句话总结 —

dub-anything 不是又一个“一键配音”，它是把配音拆成一句一句的导演活儿，让 AI 去干、让人来听。思路是对的，门槛也是真的高：Windows、N 卡、40G 硬盘、一部片子小半天，外加暂时不支持配成中文。有卡的可以先拿一段自己有权用的短片试试水，没卡的先收藏，等它往 Linux 和中文方向走一走。
