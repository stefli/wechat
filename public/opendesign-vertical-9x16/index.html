【公众号账号】

横屏产品介绍片做好了，一发抖音、视频号，画面左右被裁成黑边，标题贴边看不清。问题往往不在「会不会做动效」，而在提示词默认仍写 16:9，竖屏平台按 9:16 裁切后构图全乱。

今晚只办一件事：在 Open Design 里选 动效设计，用一条写清 9:16 / 1080×1920 的竖屏提示词，按「上标题 / 中演示 / 下字幕」三区跑出一支能发竖屏平台的产品介绍片，并按比例验收。通道怎么省额度另有专文，这里只指路一句。

 

—先定画幅，再谈提示词—

默认建议：要发抖音 / 视频号 / 小红书，提示词第一行就把画幅钉死为 9:16（1080×1920），并写明「不要 16:9」。横屏官网 Banner、投影汇报另走 16:9，两条配方不要混在同一条提示词里。

为什么先定画幅：动效底层 HyperFrames 按你写的比例排版。你写 16:9，它就按横构图放大标题与主画面；你事后再「裁成竖屏」，中区会被切掉，下区字幕常贴进平台底栏。

  • 适合今晚跟做：已有产品名、一句话卖点、三幕动作，要出一支约 15 秒竖屏介绍片
  • 可以先停：卖点还没写清、材料还是横屏演示片想「硬裁」充数——先补文案与竖构图，再开跑
  • 例外：只要横屏官网片，请用旧的 16:9 跟学篇，不要硬套本稿竖屏模板

 

—材料准备—

跟做前对齐这几条。缺一条，后面验收会对不上：

  1. 本机已安装 Open Design 桌面版并登录；创作类型能选到「动效设计」
  2. 产品名、一句话卖点、三幕（痛点 → 操作 → 结果）已写在备忘里
  3. 明确交付平台是竖屏（抖音 / 视频号等），目标画幅 9:16、约 15 秒、不要旁白
  4. 通道二选一已就绪：OpenDesign 官方 Cloud，或本机 Codex→Magpie→免费 DeepSeek（细节见通道专文）

提交前清空 composer 示例文案。残留示例容易被当成第二个项目；竖屏配额同样会被多烧一轮。

【广告位1】

 

—打开软件，选「动效设计」—

打开 Open Design。在输入区工具条找到创作类型，切到 动效设计——不要停在原型或落地页。选对后，才能用 HyperFrames 出 MP4。

红框：创作类型已切到「动效设计」。

 

—第1步：清空示例，只留一条竖屏任务—

你现在做：全选输入区 → 删掉示例 → 只留空白光标。工作目录指向今晚独立文件夹。竖屏与横屏配方不要写在同一条消息里。

 

—第2步：粘贴竖屏 9:16 提示词—

提示词必须同时写清：时长、9:16 / 1080×1920、三区构图、三幕、品牌色、收束口号、不要旁白。下面整段可复制（示例产品：WorkBuddy 周五周报定时任务；换成你的产品名与三幕即可）：

请用 HyperFrames 做一段约15秒、9:16（1080×1920）的中文动效短片：主题「WorkBuddy · 周五周报，设一次就自动跑」。
画幅必须是竖屏 9:16，不要 16:9。
竖构图三区固定：
上：大标题区（产品名 + 一句卖点，远离顶部安全边）
中：演示主画面（示意：设定时任务 → 授权本地笔记 → 周报自动出炉）
下：短字幕 + 结尾定格口号
三幕依次出现：
(1)周五又要加班写周报
(2)设一次定时任务，授权本地笔记
(3)周报到点自动出炉，结尾定格「关注老李的AI江湖」
风格简洁扁平、纸白#F4F0E8+橙#FF5A1F+金#FFD400配色、大标题+短字幕，节奏明快。
不要旁白音轨，不要过度花哨，不要额外做第二个无关产品，不要把关键字幕贴到左右/底部安全区外。

改产品时保留「9:16（1080×1920）」与「上 / 中 / 下」三区句；不要删掉「不要 16:9」，这是防模型回退横屏的硬约束。

红框：提示词区、动效设计标签、运行按钮（结构示意；请粘贴上文竖屏 pre，勿沿用屏内旧横屏文案）。

 

—第3步：通道只确认芯片（不复述专文）—

设置里看清当前模型芯片即可：有 Magpie 就走本机 Codex CLI；没有就用官方 Cloud。Cloud 免费档怎么扣、Codex 怎么指到 Magpie，各自有专文——本稿只要求你别跑错芯片。

红框：本机 CLI 列表里选中 Codex CLI（有 Magpie 时的推荐通道）。

 

—第4步：只运行一次，等竖屏 MP4—

确认创作类型仍是动效设计、提示词只有一条且含 9:16、通道芯片正确，然后点 运行。只点一次。规划与渲染可能到数分钟。MP4 一落地就停；若 Agent 还想开第二个无关项目，手动停止。

 

本篇竖屏成片样例走的是 HyperFrames 直渲（按同一条竖屏提示词结构手写分镜再渲染）。Open Design「动效设计」GUI 里点运行、看完成态的步骤仍然成立；界面含 9:16 / 竖屏芯片的新截图若尚未补齐，以设置页与提示词区旧真屏跟步骤，不要把成片帧误认成 OD 导出对话框。

—第5步：按比例与三区验收—

验收先看画幅，再看内容。打开导出的 MP4 属性或用播放器看分辨率：

  1. 分辨率是 1080×1920（或等价 9:16），不是 1920×1080
  2. 时长接近约 15 秒；无旁白音轨（若你写了不要）
  3. 三幕顺序对：痛点 → 操作 → 结果 / 口号定格
  4. 上区标题可读、中区演示完整、下区字幕不进平台底栏安全区
  5. 通道符合预期：本机路径下 Cloud 额度不应被啃

若导出仍是 16:9：不要硬裁充数。回到提示词检查是否丢掉「9:16 / 不要 16:9」，清空后只跑一次竖屏版。

自绘示意：上标题 / 中演示 / 下字幕——写进提示词，验收时按这三区对照。

【广告位2】

 

—我的经验教训—

我最早把横屏提示词改两个字就送去跑，结果仍出 16:9——模型吃的是整段约束，不是你心里的「这次要竖屏」。后来固定把 9:16（1080×1920） 和 不要 16:9 写进第一段，回退横屏的次数明显下降。

第二件：竖屏最怕字幕贴底。我有一版口号好看，发抖音被进度条挡住。提示词里写清「下区避开底部安全区」，验收时用手机全屏看一遍，比只看桌面播放器靠谱。

第三件：三区写进提示词，比事后在时间轴上挪图层省事。上标题、中演示、下字幕——读者平台一眼扫得完；你要是把关键操作塞进上下两条细边，竖屏上会糊成一团。

 

—最后—

竖屏产品介绍片的分水岭是 画幅写进提示词，不是事后裁切。Open Design 动效设计可以出约 15 秒竖片；前提是 9:16、三区构图、三幕卖点一次说清。

今晚跟做链：选动效设计 → 清空示例 → 贴竖屏模板 → 确认通道芯片 → 只跑一次 → 按 1080×1920 与三区验收。横屏需求走 16:9 旧配方；通道细节去读专文。

卖点没写清、或验收仍是 16:9 时，先改提示词再跑，不要连跑三版「再好看一点」。
