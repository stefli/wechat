【公众号账号】

想做出一个立体小人，常见的想法是先找一张照片，丢进「照片转三维」的工具里；或者一上来就想捏五官、做衣服，盼着一次出精致角色。这些路都在，只是门槛不低，还没开始就容易卡住。

我这次换一条更短的路。打开 Dust3D，先不导入照片，也不去动欢迎页上已经摆着的模型。眼前是一块几乎空白的画布。要做的事很具体：在画布上点出头和手脚。

点完这些点，旁边的预览会不会跟着长出一个能转着看的小人？我按这个顺序做了一遍。

 

—先从官网把软件放到电脑上—

先打开官网 dust3d.org，找到 Quick Start 里 Linux 这一栏。按说明下载 AppImage。我把它放到了 Applications 文件夹里。

给它加上可执行权限，再在电脑上打开。用当前版即可，不必盯着某一个发行号。

官方页面上的启动命令是这样写的：

chmod +x dust3d-*.AppImage
./dust3d-*.AppImage

如果打不开，官网还写了要先安装 FUSE 组件。我这边打开时没有再额外处理这一步。

官网 Quick Start 页。红框罩住 Linux 这一栏的下载和运行说明。我按这里下载 AppImage。

红框标出的是已经放到 Applications 文件夹里的安装包。加上可执行权限后，在电脑上打开即可。

【广告位1】

—打开之后，先进入空白画布—

软件打开后，欢迎页上会看到一些现成的箱子、鸡、羊。那是装饰，不是你刚做出来的模型。不要把欢迎页上的装饰模型当成自己做出来的结果。

页面上有 Start。点它会先要求导入正视图和侧视图的背景图。这次我没有准备这类底图，也不走这一步。

我改为打开一份还没有节点的空白工程。画布上只剩下橙色和绿色两个小三角标记，中间是空的。这就是起点。

打开空白工程后的画布。只有橙色和绿色两个小三角标记，还没有点上节点。

 

—第1步：在前视图点出头、躯干和手脚—

前视图在左侧，线条是橙色的。我先点出一条中轴线：骨盆、胸、颈、头。再从胸部分出左臂和右臂，从骨盆分出左腿和右腿。右腿我多点了一节，把大腿和脚分开。前视图上大约 9 个节点，用边连起来。

点的时候不要贪多，也不要在画面上随意洒点。先做出一个站得住的四肢结构，比一次堆很多节点更要紧。

点完后，我核对前视图里能不能看出头、躯干和四肢的位置。

红框罩住前视图的骨架：头、躯干和四肢已经点上，并用边连好。

—第2步：在侧视图把两臂前后错开—

侧视图在中间，线条偏绿。如果两只手臂在侧视图里还叠在同一条线上，转过去看时会不好分辨前后。

我在侧视图里把左臂和右臂前后错开，再看一眼绿色骨架是不是已经分开。

—第3步：看预览里是不是已经长出小人—

骨架一点上，角落里的 3D 预览并不是等你全部做完才出现。它会跟着节点实时长出体积。

我把目光从平面骨架转到预览：头、躯干、左右臂、左右腿都有块面，能认出是一个站着的极简小人。它是低模，块面很清楚，不是精致角色，也不是把照片变成的模型。

所以你下次可以先盯着预览，看它是不是已经「像一个人」，再决定要不要继续加节点。

红框罩住角落的 3D 预览。骨架点好后，这里已经长出一个能认出的极简小人。

—第4步：转一圈，确认它是立体的—

还要再确认一件事：预览里看到的不是一张平面图。

我用菜单里的 View → Toggle Rotation，也可以按快捷键 R，把模型转到另一个角度。头和四肢的前后关系跟着变了，能看出它是有体积的。

红框罩住旋转后的预览。头和四肢的前后关系变了，能看出它是立体的。

—第5步：导出一份练习用的模型—

确认能认出、也能转着看之后，我把结果存到 我的文档 / 立体角色 文件夹。工程文件命名为 练习角色，同时再导出一份练习用的模型。导出时选常见的三维模型格式即可。

打开这个文件夹，核对自己要的文件是不是已经出现。

上面红框罩住保存路径，下面红框罩住文件名和要导出的格式。我把它存到我的文档 / 立体角色。

红框标出的是已经出现的练习用模型，大小显示为 100.0 KiB。同一文件夹里还有工程文件「练习角色」。

 

—怎么验收—

我当时按这几条核对。

  1. 空白画布上已经点出头、躯干和四肢，不是欢迎页上的现成装饰。
  2. 3D 预览里能认出一个站立的极简小人，头和手脚都有体积。
  3. 换一个角度后，它仍然是立体的，不是一张平贴的图。
  4. 在 我的文档 / 立体角色 里，出现了名为 练习角色 的工程文件，以及一份练习用的模型。我这边导出的模型显示为 100.0 KiB。

所以你下次也可以用同一组标准验收：能认出、能转、文件确实写到了指定文件夹。

【广告位2】

—我的经验教训—

我先有一次把节点点得很乱，预览里长出来的是认不出形状的块状物。后来改成先排骨盆到头的中轴，再分四肢，预览立刻清楚多了。你要是刚打开也觉得「怎么不像人」，先检查节点是不是按身体结构连上的，不要继续往上堆点。

还有几件我后来才看明白的事。欢迎页上的装饰模型很容易让人误会「我已经有角色了」，其实那不是这次练出来的。Start 会要背景图，不想导入底图，就不要走那一步，改从空白工程开始。我想找新建菜单时，没有看到单独的新建项，找不到是正常的。

这次只做到点骨架、看实时网格、旋转查看、导出练习模型。绑定、动画、从照片重建三维，我都没有测。官网介绍里有这些能力，但不等于这次已经带着你做完。不要把这篇当成照片转三维，或精致角色教程。

—最后—

想做出一个立体小人，不必一上来就对付照片和精致五官。先在空白画布上点出头、躯干和手脚，看着预览里长出一个能认出、能转着看的极简小人，再导出一份练习用的模型。这条路今晚就能试。
