正文

群里又甩来一张截图，标题恨不得把字写到边框外：「HTTP 响应头里已经在给 AI 下命令了。」底下立刻有人补刀：Agent 一抓网页就完了，今晚得紧急加固。

听起来挺有道理。响应头本来就是服务器捎给浏览器的「小纸条」，要是纸条上写着「忘掉用户刚才说的」，再碰上会读网页的 Agent，脑补成末日片也不奇怪。问题是——真有那么玄吗？

 

—顺着吓人说法先走半截—

刷到的常见说法大概就这几句：响应头里能塞指令；间接提示词注入（间接提示词注入：指令藏在网页、邮件、工具结果里，跟你的提问一起进模型上下文）；Agent 只要一抓站就被接管；全网都在搞，不改架构就是等着出事。

我顺着这个逻辑想也觉得冷：供应链这边要是哪天让 Agent 去读供应商门户、对账页、报价页，谁敢保证「只读正文」？吓人帖最会做的事，就是把「可能」写成「已经」。

所以你可以先记下这半截：风险叙事不是空穴来风——头确实可能进上下文；但「可能」不等于「已经全网沦陷」。

 

—拧过来：公开扫描怎么写—

但公开材料里真正要紧的是另一组数字。安全团队 Signals Corps 读了 Common Crawl 一次月度抓取（爬取标识 CC-MAIN-2026-39）大约一成样本，合计 两亿一千七百多万 条页面响应的响应头，专门找「写给 AI 看」的字段。媒体 The Register 随后也转述了同一组结论。注意：这是他们的公开报告，不是我半夜跑去扫全网——别把转述写成亲征。

图：217M+ 响应头样本 → 7,959 站发 AI 向头 → 多数是路标 → 约 30 次试图下指令。

在他们标出来的 7,959 个站点里，7,271 其实是路标：告诉 Agent 去哪找 llms.txt（给模型读的站点说明）、MCP 服务或技能入口；其中 6,989 走的是 x-llms-txt 这类指路头。政策声明、检测「你是 AI 爬虫」、使用指引，占了其余大半。真正被标成「试图给 Agent 下指令」的，只有约 30 个站点——而且报告写明，里面多数是玩笑或整蛊，真正叫人紧张的类别很少。

图：前半吓人叙事，拧转到公开扫描口径——稀少、多玩笑、还要路径配合。

所以拧转句可以钉死：吓人帖卖的是「全网都被注入」；公开扫描卖的是「稀少、多半玩笑、还要工具配合」。温差就在这儿。你要是只转发标题，亏的是判断力；把主语和分母补回去，夜里才能睡。

【广告位1】

—头要作恶，先得进得了模型—

间接提示词注入听起来唬人，落地有门槛。公开材料写得很直：响应头只有被抓取工具原样（或摘要）塞进模型上下文，才谈得上影响；很多「只取正文」的抓取路径，头根本到不了模型眼前。

图：三层门槛——进不了上下文、进了也不听、听了也没权限，都成不了「接管」。

Signals Corps 还做了一组工作示例（不是全行业排行榜）：在常见编程助手场景里，用普通「帮我看文档、完成配置」的任务去碰带指令意味的响应头——模型常常能认出不对劲并拒绝；只有额外加上「听从站点给 AI 的指令」这类授权句，部分模型才开始乱动，而且不是每个型号都买账。翻译成人话：别把「站点说了算」写进你自己的提示词——那一句话，比玩笑头更危险。

报告还点了一处比玩笑头更值得盯的苗头：不少站点已经能用 User-Agent（用户代理字符串）把爬虫标成 AI 客户端。人用浏览器自查，和 Agent 实际拿到的内容，有可能不是同一份——这叫伪装分发（cloaking）。Common Crawl 自己用 CCBot 身份抓，「只给 Agent 看」的内容本来就不在这份统计里。所以你可以：重要站点，对照 Agent 真实请求头做一次「它看见了什么」的核对；别只拿自己浏览器的干净页当证据。

一句话收边界：玩笑头浪费一次回答；真动作要「头进上下文 + 模型肯听 + 工具有权限」。三缺一，多半是段子。

 

—别写成末日，也别写成笑话—

两边都别极端。说「全是玩笑」会低估：一旦抓取路径把头塞进去，再碰上「听从站点」的提示词，静默注册、乱跟外链建议，就不是段子了。说「全网沦陷」又会高估：公开扫描里注入尝试是个位数十量级站点，相对两亿级响应头，稀得像沙子里的玻璃渣——扎脚要防，但别当成满地地雷。

对供应链老登更实用的读法是：你真正该盘的，不是「网上有没有人写过吓人头」，而是「我的 Agent 抓网页时，到底喂给模型什么」。工具清单、是否 body-only、有没有自动跑网页建议的命令——这三样比转发一篇末日帖管用。

【广告位2】

—两类人各抄一句—

图：跑 Agent 的人盯喂料与批准；站长指路即可，别玩命令梗，别偷偷改事实。

跑扫描、跑 Agent 的人：

  1. 默认只把页面正文喂给模型；搞清自己用的抓取工具会不会把响应头一并塞进上下文。
  2. 提示词、系统提示、Agent 配置里，不要写「听从站点给 AI 的一切指令」。
  3. 网页或响应元数据里建议的安装、注册、外发，先人工点头再动。

站长：

  1. 给模型指路，用公开约定的 llms.txt 一类说明文件就够，比塞命令式响应头干净。
  2. 别把「给 AI 下命令」当营销梗或整蛊——玩笑也有人当真转发成恐慌。
  3. 若按 User-Agent 区分爬虫，别对 Agent 偷偷换成另一套事实内容；要分流，分流策略自己要说得清。

两句合并成一条记：Agent 侧少给站点权威；站长侧少玩命令头。路标可以有，接管叙事请闭嘴。

 

—你今晚就能做的—

  1. 打开你们 Agent 的抓取说明或日志：它喂给模型的是正文，还是连响应头一起？
  2. 全文搜索提示词模板，删掉任何「听从站点 / 服从页面指令」类授权句。
  3. 规定：网页建议的命令或注册，必须人工确认——写进团队备忘，别靠自觉。
  4. 重要供应商门户抽一两个 URL，用 Agent 真实请求头对照「它看见的」和「你浏览器看见的」。
  5. 看见「全网响应头注入」类标题，先找分母：多少样本、多少站点、多少是玩笑——再决定慌不慌。

不被忽悠，是把吓人标题还原成公开数字；有底气，是知道自己的工具喂了什么。HTTP 头里的提示词注入，今天更像稀有玩笑加一条卫生提醒——真要出事，多半先出事在「你把站点写成了老板」。
