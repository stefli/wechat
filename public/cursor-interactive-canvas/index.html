正文

Agent 一收工，聊天框里又是一大坨密密麻麻的文字表格：数字、状态挤在一起，眼睛扫两遍还是对不上。今晚我不跟它抬杠，直接点名要 Interactive Canvas（交互式画布）——让库存周转结果搬到聊天旁边，能筛选、能排序、能点。

我是老李。版本是 Cursor 3.24.18，演示目录 C:\Users\laoli\canvas-demo\\，里面就一份假数据 inventory.csv（8 行供应链库存）。结论先放前头：约 4 分 15 秒，Agent 写出 inventory-turnover-dashboard.canvas.tsx，右侧打开「供应链库存周转看板」——密密麻麻的文字表格变成能点的看板。它帮你更快看懂结果、改一版再看；不是来替代公司那套 BI。

 

—先把演示目录单独打开—

别把正在干活的大仓库一起塞进来。我只打开这个演示夹：假 CSV + 一份 README.md。侧栏也收起来，画面干净，后面截图才好看。

只开演示目录：inventory.csv + README.md（路径写成 C:\Users\laoli\canvas-demo\）

 

—提示词：点名要 Canvas，别再甩表—

关键就一句：请创建 Interactive Canvas，不要只用 markdown 表格。其余按库存周转看板写清：顶部 KPI、仓库条形图、状态分布、可筛选排序的明细表。模型我用的是界面上的 Grok 4.7 High。

请基于演示假数据 inventory.csv，创建 Cursor【Interactive Canvas】交互式看板（不要只用 markdown 表格）。
要求：
1) 标题：供应链库存周转看板（演示数据）
2) 顶部 KPI：SKU数、紧急补货数、低库存数、总在库件数
3) 图表：按仓库汇总在库量；按 status 分布
4) 可排序/可筛选的明细表
5) 必须打开 Canvas 面板

实测时把 8 行 CSV 内联进提示词更稳——少踩「打开错工作区」的坑。官方文档写 Canvas 需 Cursor 3.1+；我这边是 3.24.18。

【广告位1】

 

—四分钟出看板：聊天旁就能点—

界面显示 Worked for 4m 15s。聊天一侧还在交代改了哪个 .canvas.tsx，右边已经弹出 Inventory Turnover Dashboard：KPI 是 8 / 2 / 3 / 1,022（SKU／紧急／低库存／总在库），下面仓库条形图 + 状态环图，一眼能扫。

主图：左提示词，右 Canvas 看板（红框①顶部 KPI，②仓库图+状态环图）

往下滚，才是「能点」的部分：仓库芯片、状态芯片、搜索框、升序／降序，明细表里有可售天数、交期、状态色点。点一行还能展开补货示意——这才像一张临时工作台，不像聊天里又贴了一页纸。

交互区：仓库/状态筛选 → 搜索+排序 → 可点明细表（红框已标）

 

—对照：同一份数据，只要 Markdown—

另开一聊，故意说：只要 Markdown 表，不要 Canvas。结果上面是一大坨密密麻麻的文字表格；下面 Agent 仍塞了一张 Canvas 预览卡，还带 Open Canvas 按钮——它自己也知道，表不如看板好扫。

对比：① Markdown 密密麻麻的文字表格 ② Canvas 预览卡（同主题假库存数据）

读结果：看板赢在层级和可点。改一版：继续在聊天里说「把紧急补货筛出来」「加一列建议补货量」，比在密密麻麻的文字表格里找单元格快。别误会——这是 Agent 会话旁的工作台，不是把 FineBI／Tableau 换掉。

 

—Design 模式：点一下就能改观感—

工具栏上的 Design 点亮后，可以点选看板里的块做样式调整（截图里有「Describe the change」一类输入）。适合「数字对了，但颜色／间距还想拧一把」的人。Publish 我没点——分享链多半跟团队／付费能力有关，本稿不硬测。

Canvas 顶栏：Design 高亮（红框），旁为 Publish / Canvas

Design 模式下点选看板元素，可描述要改的样式

【广告位2】

 

—缺点直说—

① 侧栏若不折叠，Agents 窗口容易露出别的会话名——截图前务必收起。
② 提示词里若已写 canvas／KPI，别过早以为跑完了；以出现 *.canvas.tsx、「已在聊天旁打开」为准。
③ 它是会话旁的交互面板，不是接数仓的正式 BI；权限、定时刷新、多人协作别指望这一张搞定。
④ Publish／共享链未实测，别写成「一键外发」保证。

 

—一句话：文字表格改成能点的看板—

Cursor 3.24.18 + 中文点名 Interactive Canvas：假库存 CSV，大约四分钟，聊天旁就有可筛选排序的周转看板；Design 能用。价值很实在——看结果更快，改一版也更快。下次 Agent 再甩密密麻麻的文字表格，先让它把桌子铺好再聊。
