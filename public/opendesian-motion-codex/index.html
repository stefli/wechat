正文

想给产品做一段介绍动效，一打开 Open Design，模型菜单里一堆「升级后使用」，免费 Cloud 额度又薄得可怜。今天晚上我换了条路：不碰 OpenDesign Cloud，走本机 Codex CLI，让它经 Magpie 接到 WorkBuddy 的免费 DeepSeek——照样在「动效设计」里出了 15 秒片。

我是老李。结论放前头：Open Design 0.25 在 Windows 上，设置选中 Codex CLI，模型跟 CLI 默认（本机已指向 Magpie → workbuddy-ai-plugin/deepseek-v4.1-flash），一次跑通「WorkBuddy 筛简历三步」HyperFrames MP4；顶部积分 101.7K 生成前后不变，没扣 OD Cloud 额度。效果够日常产品介绍用。

欢迎去读我的另一篇——走 OpenDesign 官方 Cloud 免费档的实测；本稿聚焦本机 Codex → Magpie → 免费 DeepSeek这条通道。

 

—先看清：烧的是哪条路—

Open Design 的「动效设计」本质还是在 App 里用 HyperFrames 写片、渲染 MP4。差别在谁来当脑子：

· 本机 CLI · Codex（本稿）：扣 Magpie / WorkBuddy 免费配额，OD Cloud 美元额度不动。
· OpenDesign Cloud（另文）：界面芯片是官方模型名，会啃那点免费 $额度。
· BYOK 填 DeepSeek Key：设置里写明不便读写项目文件，动效写盘+渲染更别指望它当主力。

真屏：首页顶部积分 101.7K；本次生成前后数字未变

 

—先把通道切对本机—

打开设置 → 模型与提供商 → 段「本机 CLI」。在「你的 CLI」里点选 Codex CLI · OpenAI official CLI（我这边是 codex-cli 0.159.2），模型选「CLI 默认设置」。保存后回首页，创作区应走 CLI，而不是 Cloud 模型芯片。

本机 Codex 配置要先指到 Magpie。我这边 C:\\Users\\laoli\\.codex\\config.toml 大致是：

model_provider = "magpie"
model = "workbuddy-ai-plugin/deepseek-v4.1-flash"

Magpie 本机常见地址 http://127.0.0.1:3425，/v1/models 里能看到免费路由再开跑。没通的话，Open Design 选了 Codex 也白搭。

真屏：本机 CLI 已选中 Codex；OpenDesign Cloud 账号信息已打码

【广告位1】

 

—贴一条提示词，只跑一次—

首页创作类型选 动效设计。提交前先清空 composer 里残留的示例文案——我这次没清干净，Agent 把「习惯闯关 App」示例拼进来，理解成双交付；Motion 片已经出来，我手动点了停止，才没继续烧 Magpie。

实际粘贴的提示词（主题可按产品改）：

请用 HyperFrames 做一段约15秒、16:9 的中文动效短片：主题「WorkBuddy 筛简历三步」。三幕依次出现：(1) 上传简历 PDF → (2) AI 按岗位关键词打分筛选 → (3) 输出短名单。风格简洁扁平、蓝绿配色、大标题+短旁白字幕，节奏明快，结尾定格「三步搞定筛选」。不要旁白音轨，不要过度花哨。

只点运行一次。我这边 Codex 规划首响大约 44 秒；随后写 HyperFrames、渲染 16:9 MP4，计划里渲染段大约 4–5 分钟。底部模型条显示 Default (CLI config)——说明仍在本机 CLI，不是 Cloud。

真屏：左侧 Codex 进行中；底部 Default (CLI config)；积分仍 101.7K

真屏：Codex 已完成约 44s；给出分镜与交付计划；仍是 CLI config

 

—成片长什么样—

前面把通道切好、提示词跑完，成片就落地了。导出文件约 15.000 秒。三幕清楚：上传 PDF → 关键词打分 → 短名单，片尾定格「三步搞定筛选」。蓝绿扁平风，带轻量合成音轨（无旁白）。过场有轻微叠影，动效片常见，不碍事。工程里还有 HyperFrames 源 HTML，想改文案/配色可以二次动。

【广告位2】

 

—好用在哪，坑在哪—

好用：真能不靠 Opus、不啃 OD Cloud，做出可导出的产品介绍短片；中文界面完整；本机留下源码+MP4，日常改一版卖点也能复用这条通道。

坑也直说：
① 默认很容易绑回 OpenDesign Cloud，要主动切「本机 CLI」。
② Composer 爱夹带示例，不清空就容易双交付、多烧配额。
③ 全流程可能十几分钟；只想要短片时，MP4 一落地就停。
④ OD 界面不显示 Magpie/DeepSeek 真实费用，成本要自己在网关侧看。
⑤ Free Cloud 那点美元额度很薄，别当主力——这也是我改走本机通道的原因。

 

—结论：日常产品介绍片，这条我留下了—

需要给功能讲清楚、又不想每次啃 Cloud 额度时：Open Design 动效设计 + 本机 Codex → Magpie → 免费 DeepSeek，今天这趟证据够用——15 秒片在手，积分没动。

你要复现：装好 Magpie 并接到免费 DeepSeek → Codex 配置指向 Magpie → Open Design 设置选中 Codex CLI → 动效设计里清空示例、贴一条三幕提示词 → 只跑一次。想看官方 Cloud 免费档怎么扣那点美元额度，欢迎去读文首链到的另一篇；本稿就到这。
