正文

本地写码常开 Claude Code、Codex、Gemini CLI，Cursor 也想跟一把——以前每个工具各贴 DeepSeek Key、各写 Base URL，换模型像搬家。这篇按Magpie 中文桌面版真机走一遍：DeepSeek Key 只进 Magpie 一次，Agents 页把 Claude／Codex／Gemini 都接到 deepseek/deepseek-flash（或 deepseek/deepseek-v4-pro），本机网关 127.0.0.1:3425 统一翻译协议。文中 Key 全是示例 sk-laoli-deepseek-demo-xxxx，别拿去当真；插图均为真机中文桌面版截图。

Magpie（yetone 开源，官网 usemagpie.ai）干一件事：本机开网关，同时讲 OpenAI Chat、OpenAI Responses、Anthropic Messages、Gemini——客户端各说各话，它负责翻译。模型写成 provider/model。本稿只讲已接到 DeepSeek 的模型 id：deepseek/deepseek-flash、deepseek/deepseek-v4-pro。中文桌面版页签：Agent、供应商、网关 等。

 

—先看前提清单—

开工前先对这几条，省得装一半卡住：

① 系统：macOS / Windows / Linux 均可；Linux 桌面版要 GTK3 + WebKitGTK。

② 已装客户端：Claude Code、Codex、Gemini CLI、Pi、Hermes 等——Magpie Agent 页只列出本机已装或已有配置的 Agent；未装的不会出现可配置行。

③ DeepSeek Key：到 DeepSeek 开放平台自己申请；下文用示例 sk-laoli-deepseek-demo-xxxx，仅演示字段。

④ 本机端口：默认网关 127.0.0.1:3425；系统代理别把回环地址劫持走。

⑤ Magpie 要开着：走网关的模型，需要桌面版 App / magpie serve / 托盘在跑。

 

—装 Magpie / 打开中文桌面版—

macOS / Linux 官方一键安装（也可去 GitHub Releases 下桌面包）：

curl -fsSL https://usemagpie.ai/install.sh | sh
magpie ls

安装脚本把 magpie 丢到 ~/.local/bin（示例用户 laoli）。装完先 magpie ls。日常直接开 Magpie 中文桌面版；也可用 magpie tray / magpie serve 把网关拉起来。

图1　中文桌面全景：Magpie 窗口（真机中文桌面版截图，红框标注）

 

—配 DeepSeek（示例 API Key）—

桌面版路径：顶部切到 供应商 → + 添加供应商 → 选 DeepSeek 预设 → 粘贴 Key → 保存。命令行等价：

magpie provider add deepseek sk-laoli-deepseek-demo-xxxx
magpie provider test deepseek

Key 只进 Magpie，落在 ~/.config/magpie/providers.json；Magpie 不读 shell 环境变量。本稿真机拉到的 DeepSeek 目录项是 deepseek/deepseek-flash（界面显示 DeepSeek-V4.1-Flash）与 deepseek/deepseek-v4-pro——以你账号实际返回为准。下文示例 Key 纯属演示，请换成你自己的。

图3　网关模型列表筛选 deepseek：deepseek/deepseek-flash、deepseek/deepseek-v4-pro（真机中文桌面版截图，红框标注）

 

【广告位1】

 

—验证网关通了（网关 3425）—

配完先看桌面版 网关 页：状态应显示运行中，右侧 http://127.0.0.1:3425。「接入」区可切换 OpenAI / Responses / Anthropic / Gemini，Base URL、API key（填 magpie 即可）、Shell 导出都在这里。命令行再测：

magpie provider test deepseek
curl -s http://127.0.0.1:3425/api/hello
magpie models

/api/hello 返回带 name: magpie 就说明网关活着。通用客户端若要手填，常用变量是：

OPENAI_BASE_URL=http://127.0.0.1:3425/v1 OPENAI_API_KEY=magpie
ANTHROPIC_BASE_URL=http://127.0.0.1:3425 ANTHROPIC_API_KEY=magpie
GOOGLE_GEMINI_BASE_URL=http://127.0.0.1:3425 GEMINI_API_KEY=magpie

对 Magpie Agent 列表里的客户端，一般不用自己 export——在 Agent 页点模型，它会改对方配置。上面三行是给「只有 Base URL 设置」的其它工具用的。注意：网关「模型」演示字段可能残留其它 provider 示例；本稿 Agents 实际接线只用 DeepSeek 目录 id。

图4　网关接入：127.0.0.1:3425、Base URL /v1、OPENAI 导出（真机中文桌面版截图，红框标注）

 

—在 Claude 里接 DeepSeek—

回到 Agent 页，Claude Code 模型下拉选 deepseek/deepseek-flash（界面或显示 DeepSeek-V4.1-Flash）；也可：

magpie claude deepseek/deepseek-flash

Magpie 会改 ~/.claude/settings.json 的 env：ANTHROPIC_BASE_URL=http://127.0.0.1:3425、ANTHROPIC_AUTH_TOKEN=magpie，以及模型相关变量。Claude Code 仍讲 Anthropic Messages；由网关翻译到 DeepSeek。改完请开新会话。想恢复官方模型：选回原生模型，或 magpie claude default。

图5　Agent → Claude Code：已接入 DeepSeek（真机中文桌面版截图，红框标注）

 

—Gemini CLI 也接到 DeepSeek—

Agent 页里 Gemini CLI 显示已接入后，同样选 DeepSeek 目录项；或：

magpie gemini deepseek/deepseek-flash

Magpie 写入 Gemini CLI 配置：GOOGLE_GEMINI_BASE_URL 指向网关，API-key 鉴权，模型选 DeepSeek 目录项（不是 Google 官方模型 id）。Gemini CLI 原生讲 Gemini 协议；网关负责和 DeepSeek 侧互译。Google AI Studio 网页端不走你这台 Magpie。

图6　Agent → Gemini CLI：已接入 DeepSeek（真机中文桌面版截图，红框标注）

 

—Cursor（诚实说边界）—

真机中文 Agent 列表没有 Cursor 行（见截图备注）；CLI 侧 Magpie 报 Can't connect／缺少 cli-config.json——别指望一键接管 Cursor IDE 订阅聊天。能走的旁路：

OpenAI 兼容 Base URL：填 http://127.0.0.1:3425/v1，Key 填 magpie，模型填 deepseek/deepseek-flash。本稿用 curl 旁路实测回复 pong。

Cursor CLI：若本机写出 ~/.cursor/cli-config.json，可再试 magpie cursor deepseek/deepseek-flash（以本机版本为准）。

Private Inference：特殊构建可读 CURSOR_LOCAL_AGENT_BASE_URL（…/v1）；普通订阅聊天不一定能整站改址。

图7　Cursor：Can't connect；OpenAI Base URL 旁路仍可走 DeepSeek（说明卡，依据真机备注与 CLI 实测）

 

【广告位2】

 

—Pi 接到 DeepSeek—

Pi（@earendil-works/pi-coding-agent）需要 Node ≥22.19。本稿用 fnm 升到 Node v22.23.3 后执行：npm install -g --ignore-scripts @earendil-works/pi-coding-agent（也可用 curl -fsSL https://pi.dev/install.sh | sh）。装完出现 ~/.pi/agent/settings.json，再让 Magpie 接管模型——别把 DeepSeek Key 贴进 Pi。

magpie pi deepseek/deepseek-flash
# 冒烟（必须关掉 stdin，否则 -p 可能挂起）
pi -p --no-session --no-tools --thinking off \
--provider magpie --model deepseek/deepseek-flash --api-key magpie \
"只回复：pong" </dev/null

实测：Pi 1.3.0 · magpie ls 显示 magpie/deepseek/deepseek-flash · 约 2.85s 回 pong（PASS）。

图8　Pi：已装并经 Magpie 接到 DeepSeek（说明卡 · CLI 实测 pong）

 

—Hermes 接到 DeepSeek—

Hermes Agent（Nous Research）一键安装即可；本稿用非交互：curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash 加 --non-interactive --skip-browser --skip-computer-use。跳过 Nous Portal OAuth——模型由 Magpie 供应。配置在 ~/.hermes/config.yaml；Magpie 会写入 providers.magpie（Base URL http://127.0.0.1:3425/v1，key magpie）。

magpie hermes deepseek/deepseek-flash
hermes chat -q "只回复：pong" --oneshot -Q --yolo

实测：Hermes Agent v0.22.2 · magpie/deepseek/deepseek-flash · 约 5.5s 回 pong（PASS）。

图9　Hermes：已装并经 Magpie 接到 DeepSeek（说明卡 · CLI 实测 pong）

 

—Codex 接到 DeepSeek—

Codex 原生讲 OpenAI Responses。Agent 页选 deepseek/deepseek-flash 或 deepseek/deepseek-v4-pro。Magpie 会在 ~/.codex/config.toml 写 [model_providers.magpie]。切完建议重启 Codex / 新开 session（真机提示有运行中实例待重开）。

magpie codex deepseek/deepseek-flash

—实测一下—

2026-10-16（Asia/Shanghai）在本机网关 127.0.0.1:3425 上，统一目标模型 deepseek/deepseek-flash，提示词「只回复：pong」，网关鉴权用 key magpie（不是 DeepSeek sk）。结果摘要：

通了：Gateway OpenAI（~1.25s）、Gateway Anthropic（~0.91s）、Claude Code（~4.5s）、Codex CLI（~1.7s）、Gemini CLI（~3.7s）、Pi（~2.85s）、Hermes（~5.5s）——stdout 均为 pong。

部分通：Cursor —— Magpie Can't connect；OpenAI Base URL 旁路 curl ~0.8s 得 pong。

小提示：OpenAI chat 路径上 DeepSeek Flash 可能把 token 花在 reasoning；短答请把 max_tokens 调到约 64–128，避免空 content。Gemini 无头模式需要 --skip-trust；Codex / Pi 在非交互时请关掉 stdin（</dev/null），否则可能挂起。

—本地 AI 开发一套用法建议—

一套稳妥用法：

Key 只进 Magpie——供应商加一次；客户端只拿网关地址和 magpie 令牌。

日常看三个页签——供应商加 DeepSeek → 网关确认 3425 → Agent 给各客户端选 deepseek/…。

日常用 flash，难题用 v4-pro——按活选模型，别全程顶配。

切模型开新会话——正在跑的会话仍用旧模型；Codex 注意待重开提示。

档案（profile）——magpie save work / magpie use work，整组一键切回。

 

—踩坑与边界—

能通和不能通，要讲清楚：

代理劫持 127.0.0.1——Clash / Surge 等若把回环送去代理，会出现 502。给 127.0.0.0/8 和 ::1 加直连。

Agent 不在列表——先安装并运行一次写出配置，再开 Magpie；或从「安装其他 Agent」入手。

壳里的 Key 无效——Magpie 故意不读环境变量；Key 必须加进供应商。

Cursor——Can't connect 时走 http://127.0.0.1:3425/v1 + key magpie + deepseek/deepseek-flash。

网页版官方 App——Claude.ai、Google AI 网页、ChatGPT 网页不走本机网关。

协议边界——Magpie 翻译 Chat / Responses / Anthropic / Gemini；私有协议且无 Base URL 的客户端，只能看 Magpie 是否单独适配。

Pi / Hermes 版本与 CLI 子命令可能随发行版调整；以 magpie help 与 Agent 页为准。本文插图除 Cursor／Pi／Hermes 说明卡、CLI 文本卡与 CLI 结果表外，均为真机中文桌面版截图加红框标注。

 

—收个尾—

一句话：DeepSeek Key 进 Magpie 供应商，本机 3425 当总闸，Agent 页把 Claude／Codex／Gemini／Pi／Hermes 接到 deepseek/deepseek-flash；Cursor 若 Can't connect 就走 Base URL 旁路——本稿 CLI 已打出 pong。示例 Key 记得换成你自己的；玩通了存成 profile，下回一键切回来。
