【公众号账号】

群里常有人问：桌面版能聊，可我想一条命令跑完就退出——结果进 stdout，进程自己走人。打开窗口点新会话、等气泡、再复制，那是另一条路。

卡在哪？本机 PATH 里未必有全局 dsh，一敲命令就「不是内部或外部命令」。今晚任务：问清 headless oneshot 怎么跑、没有全局 dsh 时桌面自带 cli 在哪、Web/桌面点选和脚本边界到哪。

下面按你会脱口而出的几个问题答。答案都以本机帮助与真测为准，不编造未验证旗标。

 

—headless 到底是什么？—

短答：无界面、一次任务、答完退出的 profile。

官方帮助写的是：答案走 stdout，诊断走 stderr；可从参数或管道读入任务。把它想成「一次性工单」：进来、干活、把结果吐到标准输出、走人。对话历史不是它的主场，脚本编排才是。

所以你可以：先跑通一行 oneshot，再谈管道和定时。今晚若只是想点选插件、看会话——继续用桌面版即可，不必强行 headless。

【广告位1】

 

—什么时候 Web / 桌面不够用？—

短答：你要的是「跑完返回」，不是「坐在窗口里聊」。

  • 定时脚本要调用一次 Agent 并解析输出——点 UI 接不住。
  • SSH / 无桌面环境不方便操作 GUI——终端才是主场。
  • 同一条任务要重复跑——点选会疯，oneshot 可进脚本。

图：桌面适合点选插件与看会话；要「跑完返回」时走 headless。

所以你可以：桌面负责逛与验界面；headless 负责一条命令交付。两条入口别互相顶替。

 

—我电脑没有全局 dsh，还能跑吗？—

短答：能。用桌面版自带的 dsh.cmd。

本机实测：PATH 里未必有 npm 全局 dsh；但安装目录 resources\runtime\cli\bin\dsh.cmd 可用。也可在桌面菜单用「管理 dsh 命令」注册到用户 PATH——注册后新开终端再试 dsh --version。

cd C:\Users\laoli\Documents\dsh-demo-headless-oneshot
& "C:\Users\laoli\AppData\Local\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd" --version

图：本机 version 与 headless --help；选项以你机器帮助为准，勿照抄未验证旗标。

本机帮助里常见 --json / --session-id；较新的 approval 相关选项若帮助里没有，不要照抄网上未验证参数。

所以你可以：先找到桌面自带 cli，跑通 --version，再谈 oneshot。

 

—一条命令长什么样？怎么验收？—

短答：进示例目录，headless 提问，看 stdout 是否给出完整句并退出。

dsh --profile headless "用一句话介绍 DeepSeek Harness"

本机在 C:\Users\laoli\Documents\dsh-demo-headless-oneshot 跑过：stdout 给出一句中文介绍，进程退出（exit 0）。需要机器可读事件时再加 --json（以本机 --help 为准）。

图：本机验收——stdout 给出一句中文介绍，进程退出。

所以你可以：把这行放进脚本或 CI；验收盯两件事——stdout 有完整答案、进程自己退出。

【广告位2】

 

—桌面入口和 CLI 的边界在哪？—

短答：CLI 唤不醒桌面窗口；desktop 插件要退出桌面后再改。

  1. 要 GUI：点桌面版图标。headless 不是启动桌面壳的开关。
  2. 要 oneshot：走 headless profile，结果进 stdout。
  3. 要改 desktop 插件：先退出桌面版，再对 desktop profile 动手——层别串。

停止条件：本机 dsh --profile headless --help 里没有的旗标，今晚先别用。能做的是 oneshot 跑通退出；不能做的是指望 CLI 把桌面窗口唤醒。

所以你可以：入口选对再开工——点选走桌面，脚本走 headless；没有全局命令不等于 DSH 不能脚本化。

 

—最后—

意图就一句：一条命令跑完就退出——DeepSeek Harness 的 headless oneshot 把答案打到 stdout，进程自己走人。Web/桌面点选是另一条路，别拿来互相顶替。

边界也一句：没有全局 dsh 时，用桌面版自带 cli；帮助里没有的旗标不要照抄；CLI 唤不醒桌面窗口。今晚把入口问清楚，你就不会在「命令找不到」时误以为不能脚本化。

入口对了，再谈管道和定时。下期见。
