【公众号账号】

报销票一堆、科目对不上——谁没撞过。同事丢过来一句：「你不是装了 DeepSeek Harness 吗，帮我分个类。」我说行，但今晚只办一件：在 DSH 桌面里把票理成能核对的 费用分类 表。

别一上来就信科目名。先把金额和缺票钉住，科目可以后改。

下面按普通人跟做写：打开桌面版 → 新建会话 → 指向材料夹 → 粘提示词 → 等回复 → 怎么验收。

 

—材料先放桌面—

我把示例票据放在桌面文件夹 报销票据：餐饮、出租、高铁、加油、快递、办公耗材，外加一条停车费没票的备注。一共 7 份。

  1. 六张有票票据（金额只许引用原文）
  2. 一份备注：停车费约 25 元，缺票待补
  3. 文件夹放在桌面，名字就叫「报销票据」，方便在对话里直接说

红框：桌面「报销票据」文件列表——先认材料，再打开 DSH。

【广告位1】

 

—桌面里怎么点—

打开 DeepSeek Harness 桌面版（开始菜单或桌面快捷方式）。左侧点 新会话，确认工作区是你能读到桌面文件的那个。

  1. 点「新会话」，等中间出现输入框
  2. 在输入框说明材料在桌面「报销票据」文件夹（也可点输入框旁 + 挂文件夹）
  3. 把下面提示词整段粘贴进去，点蓝色发送箭头
  4. 等状态变成「已完成」，再往下滚看表格

我当时就这么跟它说的——词表写死，缺票单独一行，禁止编金额：

请读取桌面上的「报销票据」文件夹里的全部票据与备注。

任务：整理成一张「费用分类表」。
列：日期｜费用类型｜摘要｜金额(元)｜票号｜报销人｜备注｜是否缺票
费用类型只用：交通／餐饮／差旅／快递／办公／油费／其他。
停车费没票单独一行，是否缺票=是，备注写「缺票待补」。
表后给：按费用类型小计、总金额、读到几份、明细几行、缺票几条。
金额只许引用原文，禁止编造。不要改原始文件。
用 Markdown 表格直接回复在对话里。

关键规矩：金额只许引用票据原文；缺票不要并进别的科目。

红框：桌面主对话区输入框——提示词已粘好，点发送即可。

 

—产物怎么验收—

本机桌面真跑：读到 7 份（6 票+1 备注），明细 7 行；有票合计约 1,179.90 元，缺票停车费约 25 元单列（原文写「约 25 元」，表里保留「约」字）。用时大约半分钟到一分钟。

红框：桌面主区费用分类表——日期、科目、金额与缺票行要对得上。

所以你下次可以：先对总金额，再对缺票行，最后才纠结科目叫法。

  1. 打开原票据，抽查 2～3 行金额是否一致
  2. 缺票行是否单独存在、备注是否写「缺票待补」
  3. 科目若变成会计腔（如「业务招待费」），按公司词表改一列再交

【广告位2】

 

—坑与何时停—

我写死了「交通／餐饮／…」，它仍可能甩出会计腔。表能用，但科目要以你公司词表为准。

  • 金额对不上 → 停，回原文核对，不要让它「四舍五入补齐」
  • 缺票被并进油费 → 打回，要求单独行
  • 票面模糊、扫描件看不清数字 → 先补材料再跑，别逼它猜

智能报销 不是一键过账。DeepSeek 桌面链路帮你的是「先分类、先曝光缺票」，不是替财务签字。

 

—最后—

AI办公 场景里，DSH 桌面适合先出分类草稿；交财务前，人核金额与缺票。适合票不多、格式杂的晚上；不适合无原文硬估金额。

你今晚若只做一件：打开桌面版，把词表和「缺票单列」写进提示词，跑完先对总金额，再对缺票行。

办公Agent 这条，我更愿意把它当成「下班前的整理工」。费用分类 表能交初稿，人核才能交终稿。
