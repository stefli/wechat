A｜主推版

Project Genie：开放入口，不是再发一次模型。
谷歌在2026年11月18日更新了 Project Genie 体验，11月19日再向开发者开放入口：可通过 Gemini API 的交互接口和 Google AI Studio 接入。官方写明，能连续生成720P、每秒24帧的世界，并带同步原生声音。
官片里，蚂蚁世界会在镜头移动时改色，空间站场景也能按指令召来飞船。键盘控制和文字指令可以一起用，边走边改天气、光线、物体和事件。
这不是免费全面开放。符合条件的 Google AI Ultra 用户可以试用新体验，Pro 用户仍需加入候补。API 的价格和具体权限要另查，本稿不报价格。
它仍是前沿研究工具。延迟、复杂物理和长时间场景一致性都还没彻底解决。新的是接入和创作入口，不是已经做成完整游戏引擎。本片只旁观官方演示，没有账号实测。
