# PUBLISH — Goldman Sachs restricts AI coding tools

Slug: `goldman-ai-coding-ban` · 信源见 `SOURCES.md` · B=Hypebeast 主推

## A · 主推版

能写代码的留下，交易台先交回去。

彭博 2026年11月2日独家：高盛在做完生产力和风险复盘后，限制多数员工继续使用高级AI编程工具。十月已更新内部指引；交易员和银行家用了好几个月——盯客户流水、建模仓位、起草材料——如今被收紧。

点名的工具包括 Anthropic 的 Claude Code，以及微软 GitHub 的编程相关能力。权限主要留给工程师；跨交易与量化的策略岗仍可继续用。七月，首席信息官 Marco Argenti 还夸过非技术同事用「氛围编程」；如今成鲜明对照。发言人 Nick Carcaterra 称：先试验，再把工具长期交给最合适的人。

银行没有退出人工智能：二手报道称约一万二千名工程师仍可使用这些工具，行内 GS AI Assistant 还在向约四万六千人铺开。
