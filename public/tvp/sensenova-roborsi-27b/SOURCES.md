## 核实过的事实
- 正式版将同一份仿真训练权重部署到 Piper X 与 Piper 两款真实机械臂，仅适配观测/状态/控制接口，未使用真实机器人数据训练或微调。
- Piper X 结合 VLA 与 Code as Policy 叠积木：10 次成功 9 次（90%）。Piper 通过 Code as Policy 做多类型物体抓取与放置：10 次成功 6 次（60%）。预览版在这两项分别是 3 次和 2 次；未经机器人操作训练的对照模型两项均未完成。
- 正式版可自主判断何时调用 VLA 生成动作轨迹、何时通过代码直接控制机械臂，并根据执行反馈调整。环境步执行比例：VLA 41.9%，Code as Policy 58.1%。
- RoboDojo 最新版评测：正式版平均 34.7 分，预览版 10.0 分（约 3.47 倍）；官方写明「以 27B 的模型体量超越 RoboDojo 官方团队测试的 GPT-6-Astra 的成绩」。本片转述时保留「官方对照里的」这一限定，不把它写成全面超过该模型。
- 另有双臂观察二阶魔方六个面后还原的官方演示（标注真机实拍、6 倍速）。
- 本片没有独立实测。真机成功率不是 100%，口播第 6 句写明「不是每项都十拿九稳」。
