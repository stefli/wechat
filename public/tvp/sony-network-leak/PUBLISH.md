# PUBLISH — 索尼网通 So-net 遭入侵：约 258 万会员信息外泄

## A · 主推版

索尼日本网通又出事了：So-net / plala 会员库被入侵，合计约 258 万条资料外泄——但这不是 PlayStation 用户库被拖走。
