手机和电脑共用发布状态

图文稿件库 · 科技快播稿件库

这是你主动选择的 PAT 方案，不是 GitHub OAuth 登录。请不要把 PAT 发给聊天机器人、放进链接、截图或分享。页面不会预填维护者的发布凭证。

每个浏览器首次操作

  1. 在 GitHub 创建自己的 fine-grained PAT：资源所有者 stefli，仅选 stefli/wechat，Repository permissions → Contents: Read and write（Metadata 自动只读）。无需 Actions、Workflows、Administration 权限。建议短有效期。本库仅允许 stefli 账号。
  2. 打开任一稿件库 →「发布状态设置 · GitHub PAT」，在密码框粘贴自己的 PAT，点击「验证并连接」。手机和电脑分别做一次。不要通过聊天提交 PAT。
  3. 默认只存此标签页 sessionStorage 会话；同一标签页在图文、快播间切换可沿用。关页后可能需重填。只有明确勾选「记住」才保存到此浏览器 localStorage，刷新/重启可沿用至失效或清除。

GitHub fine-grained PAT 设置。连接只先验证身份和账号仓库写权限；PAT 细分 Contents 写权限仍以实际保存成功为准。401/403 会明确报错，不能误认已保存。

安全与公开性

  • sessionStorage 和 localStorage 都不是加密保险箱；同源脚本、浏览器扩展或 XSS 可能读取。stefli.github.io 上其他同源页面也属于这一风险范围。记住 PAT 前需明确勾选。
  • 浏览器仅把 PAT 放在 api.github.com 的 Authorization 请求头，不放 URL、状态文件、导出备份或仓库。库页面不加载第三方 JavaScript。仍请使用可信设备、最小权限和短有效期，用后可在 GitHub 撤销。
  • 「断开并清除」删除本标签页会话与此浏览器记住的 PAT，保留状态和待同步队列。其他已打开标签页各自的会话 PAT 需分别断开。关闭/清空一个浏览器不会撤销 GitHub 上的 token。
  • stefli/wechat 是公开仓；publication-state/status.json 里的稿件标识、平台、状态、发布日期以及 Git 提交历史均公开可见，不要写私人备注或联系资料。
  • GitHub Contents 权限为整个所选仓库，不是仅一个文件；前端限制本功能只写状态路径，但这不是 GitHub 提供的文件级权限。

旧状态怎么迁移

  • 每个设备/浏览器首次连接并读到 GitHub 状态后，原 laoli-library-status-v1 会先原样备份；不删除、不改写旧键。
  • 旧「已发/不发」记录仅在远端缺少该条平台记录时排队迁移；旧默认「未发」不会覆盖远端有效记录。原发布日期保持原值，未记录日期的不会编造。
  • 旧记录和 GitHub 不同时会列出逐项冲突，你选「采用 GitHub」或「保留本机并同步」。不会拿某台旧设备的整库快照覆盖新数据。
  • 尚未访问/连接的手机或电脑数据不可能提前迁移。它们需各自打开页面并连接，才读取自己的旧状态。
  • 「下载状态备份」只含状态缓存及旧数据备份，不含 PAT。日常同步不需要导入导出；建议在迁移前另存一份备份。

日常使用与故障

  • 点击平台标签按「未发 → 已发 → 不发」切换；已发时可修改日期。切换状态保留已有发布日期。默认日期按上海时区生成。
  • 已登录且页面前台时约 20 秒读取 GitHub API，返回前台/恢复网络会刷新，也可点「立即同步」。不等待 Pages 部署，不读带缓存的 Pages JSON。
  • 「本机待同步」「远端保存未确认」「冲突」「PAT 无效」都不是已同步。离线修改保留在本机队列，恢复网络后重试；同一平台被两设备修改会提示冲突。不同平台逐条合并。
  • 同浏览器多标签使用 Web Locks 串行化缓存和请求，避免互相覆盖。需要支持 Web Locks 的新版浏览器；不支持时只显示状态，禁用修改和同步。
  • 状态写入会产生 Git 提交，可能比数据库慢；状态专用提交不会触发整站 Pages 部署。正文、视频、文章内容和社交平台不受本功能修改。
  • 没有 PAT 的设备仅能看到本机缓存/旧数据，不会声称已与远端同步。配置失效时重新输入自己的 PAT，不需要清除旧状态。

核验范围

开发回归测试与两个独立存储客户端的真实 GitHub API 读写验证，不等于已配置你的手机/电脑。上线后请自行连接两端，确认 A 标已发（日期一致）→ B 可见，B 改不发 → A 可见；未完成这一步前不能说你的设备数据都已迁移。
