【公众号账号】

周五催 周报 的人，从来不管你素材散在几个夹。拜访纪要在一个地方，数字备忘在另一个地方，风险又单独躺着——拼到自己都不想看。

今晚只办一件：打开 DeepSeek Harness 桌面版，把周报素材夹压成一页能改的草稿。别指望直接转发领导；能改着交，就已经比从零开写强。

步骤跟教同事用办公软件一样：材料放齐 → 新会话 → 粘提示词 → 等回复 → 验收数字与拍板项。下面按这个顺序写。

 

—素材夹放桌面—

我准备了拜访纪要、交付进度、风险待确认、数字备忘四份 md，放在桌面 周报素材 夹。材料不求多，求能对上数字：出货托数、询价家数、异常票数——这些要在素材里先写清楚，模型才能引用，而不是发明。

  1. 拜访纪要：周一／周三／周五对齐过什么
  2. 交付进度：项目 A／B／C 当前状态
  3. 风险待确认：超预算、延期、未批不排产
  4. 数字备忘：出货、异常、新询价

红框：桌面「周报素材」四份 md——先齐再开 DSH。

【广告位1】

 

—桌面里怎么点—

打开 DSH 桌面版 → 点 新会话 → 在输入框写明材料在桌面「周报素材」→ 粘贴下面提示词 → 发送。

结构写死，比让它「自由发挥周报」稳：

请读取桌面上的「周报素材」文件夹里的全部 md 文件。

任务：压成一页「周报草稿」，结构固定为：
1）本周进展（条目，带数字）
2）风险与卡点
3）下周计划
4）需要领导拍板的事
数字只许引用素材原文，禁止编造。用 Markdown 直接回复在对话里。不要改原始文件。

红框：桌面主区输入框——周报结构提示词已粘好。

 

—草稿怎么验收—

桌面真跑后，出货 12 托、新询价 2 家、在途异常 1 票 都对上了；冷链超预算 8% 是否改规格留在「需要领导拍板」。

红框：桌面主区周报草稿——进展、风险、拍板项要对着素材。

所以你下次可以：先删抒情句，再只改拍板项。我自己的改稿顺序很土：先盯数字是否来自素材，再看风险有没有被写成定论，最后只改「需要领导拍板」那几条。

草稿能交一版不丢人的周报，靠的是结构锁死和待核留着，不是模型替你把业务想圆。

【广告位2】

 

—坑与何时停—

素材没写的承诺，它有时爱补全。没写过的客户承诺一律删或改成待核。

  • 数字对不上素材 → 回原文，不要让它「估算补齐」
  • 出现未写过的客户承诺 → 删或改待核
  • 下周计划写成愿望清单 → 压回可执行的几条

 

—最后—

适合素材齐、只差拼装的晚上；不适合素材本身还是空白。AI办公：桌面打开 DSH → 粘结构提示词 → 人改拍板项。

DeepSeek Harness 帮你的是结构，不是替你对业务负责。周五催表时，有一页能改的草稿就够用。

你若只带走一句：结构写死、拍板项留着、承诺不瞎补——周报这条在桌面里就站得住。
