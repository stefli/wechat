正文

朋友截了张 agent 账单：大半页都是「好的我来帮你看一下」。群里有人说装 Caveman，少废话，能省大约六成。马上有人追问：这是真少生成，还是只把长文藏起来显示？我是老李。下面说清楚：它干什么、是不是真省 token、怎么装、中英测到多少、推不推给朋友。

 

—这是做什么的—

Caveman 用来给 coding agent 少说话、少读废话。它不是换一个新模型。常见就两块主功能：

1. skill（少说话）

让 agent 回复变短，代码和数字照样保留。

2. 本地代理（少读废话）

把日志、JSON、测试输出压短，再喂给模型看。

另外还有这些（可选，不是这篇主测）：

1. 自动选模型 / 力度（Auto）

2. 脚本复用（Blocks）

社区常喊「省约 65%」，那是口号和精选例子，不是你装上就稳拿的账单折扣。官方诚实页也写了：如果你本来就说「请简洁」，再开 /caveman，多省的往往不多；/ultracave 更短一些。按「请求次数」计费的工具，回复再短也不省次数。

 

—真省 token，还是只精简显示？—

很多人会问：Caveman 是让大模型少生成，还是完整返回后再截短显示、账单其实没少？结论先说：skill 模式下，不是「后台仍吐长文再截短给你看」。模型被规则约束，直接短答；输出 token 通常真的变少。

1. Say less / skill（/caveman）

改的是模型怎么答。输出 token 通常真少。按 token 计费才省钱；按「请求次数」计费不省次数。

2. Read less / 本地代理

压的是喂给模型之前的日志、JSON、测试输出。主要省输入 token。也不是显示层精简。

本篇数字来自 skill 口吻的装前装后对照（用 o200k 数答文）。没把「代理压输入」的会话账单写成 65%。官方文档与诚实页也按「输出变短 / 输入压缩」分写，没有写成 UI 截断。

 

—怎么装、怎么开—

我用的测试目录：/home/laoli/projects/laoli-demo-caveman-token-diet/。先确认 Node ≥22.13。完整安装（CLI，当前版）：

npx @caveman-ai/cli@latest
# 装完自查
cave --version
# 可选：接到 OpenCode（不想上报统计就加 DO_NOT_TRACK=1）
DO_NOT_TRACK=1 cave setup --yes --agents opencode

只想让它少说话、不装代理，用 skill 就行：

npx skills add JuliusBrussee/caveman -g
# 对话里打开
/caveman
# 更短
/ultracave
# 关掉
stop caveman
# 或
/caveman off

本机已装上 CLI 当前版，skill 在 ~/.agents/skills/caveman。文档还写了 30 多家 agent 的接法。不想上报：装的时候带 DO_NOT_TRACK=1，或事后 cave telemetry off。

本机：安装命令、cave --version（版号已遮）、Node 版本、已装 skill 列表

【广告位2】

 

—推荐给谁，不推荐给谁—

可以推荐给朋友，如果他符合这些：

1. 按 token 付费

2. agent 经常车轱辘话

3. 日常多是解释代码、改小函数

4. 愿意花十分钟做装前装后对照

这类人先开 /caveman 就够用，代理那套可以以后再说。

先别推，或让他先别开：

1. 按「请求次数」计费（短回复不省次数）

2. 团队提示词已经写死「务必极简」

3. 正在做逐步确认、安全警告、不可逆操作（短句容易漏条件）

4. 自己一比发现账单更高 → 用 /caveman off 关掉就行

一句结论：值得让「按 token 花钱、又烦 agent 废话」的朋友试；别当成人人装了就省六成的神药。

 

—今晚你可以这样做—

1. 确认 Node ≥22.13，跑 npx @caveman-ai/cli@latest，或只装 skill。
2. 对话里开 /caveman。
3. 同一道真题，装前装后各答一次，比 token 或账单。
4. 看答案还准不准、否定句还在不在。
5. 不划算就关掉，别硬扛口号。

装上不难。关键是用自己的题比一遍，再决定推不推给朋友。
