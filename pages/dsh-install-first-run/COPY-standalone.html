正文

下班后想试 DeepSeek Harness（简称 DSH），结果卡在三件事：开始菜单找不到、模型 Key 不知道往哪填、工作区路径一脸懵。

今晚任务只有一件：把桌面版打开，配好模型，建好工作区，跑通第一句。

能不能一次过？取决于你有没有把「入口、Key、工作区」三件事按顺序钉死——下面按清单走。

- - -

先搞清它是什么

DSH 是 DeepSeek 官方的智能体宿主：桌面壳 + 本机工作区 + 插件栈。它不是又一个网页聊天框，而是让 Agent 在你本机目录里干活的壳。

桌面版打开后，左侧是新会话、插件、工作区；中间是对话；底部是输入框。配置与会话落在用户目录下的 .dsh，工作区则是你自己选的文件夹。

红框：侧栏「新会话」与「默认工作区」——今晚先认这两个入口。

材料放哪：示例目录用 我的文档\dsh-demo-install-first-run（正文虚拟用户 laoli）。别直接占用你正在写的工程。

【广告位1】

出什么问题：三道常见卡点

卡点一：找不到入口。装完只记得下载了安装包，开始菜单搜「DeepSeek Harness」才打开；托盘里关窗不等于退出。

卡点二：Key。欢迎页或设置里要配官方 API Key / 账号；Key 只进本机凭据，不要贴进聊天、截图、笔记外传。

卡点三：工作区。没选文件夹就开干，Agent 不知道读写边界；选到别人的工程更糟。

- - -

怎么解决：今晚装通清单

  1. 打开桌面版：开始菜单搜 DeepSeek Harness，等到主界面侧栏出现「新会话」。
  2. 配模型：按欢迎页/设置走完官方 Key 或账号；保存后进工作区。不要把 Key 写进会话正文。
  3. 建工作区：用独立示例夹，例如 C:\Users\laoli\Documents\dsh-demo-install-first-run。
  4. 新会话 + 第一句：点「新会话」，在底部输入框发一句最小问题，例如「用一句话介绍 DeepSeek Harness」。
  5. 验收：对话区出现一句可读回复；侧栏能看到该会话。

红框：底部输入框与「默认工作区 / 标准模式」——第一句从这里发。

本机实测里，桌面 UI 的输入框用自动化键入不稳定；我改用同一套桌面版自带的命令行，在示例目录跑：

dsh --profile headless "用一句话介绍 DeepSeek Harness"

stdout 给出了一句中文介绍，命令退出码 0——第一句算跑通。桌面聊天框你今晚手动点一下发送即可，路径与验收标准相同。

同一晚验收：示例目录下 headless 跑通一句中文介绍并退出。

装通后侧栏能进「插件」页——下一篇再讲别装乱。

【广告位2】

坑与何时停

  • 关窗≠退出：Windows 托盘可能还在跑；装插件前要「退出 DeepSeek Harness」。
  • Key 进截图：设置页有 Key 时先遮住再拍；正文永远不写真实 Key。
  • 占用当前工程：先建示例夹，再选为工作区。
  • 版本号执念：跟着当前桌面版走即可，不必死盯某个小版本号。

停止条件：欢迎页过不去、Key 无效、或工作区无权写入——先停，修好再谈插件。

你今晚就能做的

  1. 打开桌面版，确认侧栏有「新会话」和「工作区」。
  2. 建好示例夹并选为工作区。
  3. 发一句最小问题，或用自带 dsh --profile headless "…" 验收。
  4. 截一张无 Key 的主界面留底；Key 相关画面不要外传。
  5. 若只想聊天网页、不需要本机工作区——可以停，不必硬上桌面版。

装通了，心里会松一点：入口清楚、Key 有地方放、工作区有边界。下一篇专门讲「一切皆插件」，避免你今晚手痒乱装。
