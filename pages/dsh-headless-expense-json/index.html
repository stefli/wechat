【公众号账号】

费用材料常按夹拆：差旅一夹、办公一夹、招待一夹。你要的不是再开三个聊天窗口，而是在 DeepSeek Harness 桌面里 一次汇总多夹，还能把结果留下来。

卡点很具体：夹多了就容易漏行、漏加总。今晚只办一件——桌面新会话读完「费用批跑示例」，贴出明细、小计和可复制汇总。

下面按普通人跟做写：材料认清 → 桌面点选 → 粘提示词 → 核对总计。

 

—材料放桌面—

示例放在桌面 费用批跑示例：差旅、办公、招待三类条目文件。一共 8 条原始记录，金额只许引用原文。

  1. trip-shanghai_items.txt：高铁 / 酒店 / 地铁
  2. office-supplies_items.txt：打印纸 / 硒鼓 / 快递袋
  3. client-dinner_items.txt：晚宴 / 打车

红框：桌面「费用批跑示例」三类材料文件。

材料认清之后，先别急着点发送。桌面版跟命令行最大的差别，就是你能看见输入框、发送键和回复区——照着点就行，像教同事用办公软件。跟做前先确认 DeepSeek Harness 桌面窗能打开、能新建会话；提示词整段复制即可，不用自己改写口径。

【广告位1】

 

—桌面里怎么点—

打开 DSH 桌面版 → 点 新会话 → 说明材料在桌面「费用批跑示例」→ 粘贴提示词 → 发送。等回复出现明细表和小计再验收。

请再次读取桌面上的「费用批跑示例」文件夹里的全部费用材料（含子文件）。

任务：在桌面会话里一次汇总多夹费用。
务必把结果直接贴在对话里（不要只存文件）：
1）明细表：来源夹｜摘要｜金额(元)
2）按来源夹小计与总计（数字只许引用原文）
3）附一段可复制 JSON：[{source,summary,amount}, ...] 与 grand_total
金额禁止编造。用 Markdown 表格直接回复。不要改原始文件。

若它只丢一个文件卡片却不贴表，补一句：请把明细和小计直接贴回对话。

红框：桌面主区——多夹汇总提示词已粘贴。

 

—产物怎么验收—

桌面真跑后：差旅小计 1879、办公 1089、招待 1988，明细 8 行都能对回原文。模型若把总计写成 3957，你要用计算器核：1879+1089+1988=4956——这正是人核要抓的点，不要盲信 grand_total。

红框：桌面主区明细表与小计结果。

验收时只盯你关心的那几格数字。表好看不重要，对得上原文才重要。桌面主区能看见的内容，这篇才算跟做完成。交稿前再问两句：数字能不能在原文件找到？需人核的行有没有留着？两句都过，这篇才算落地。

【广告位2】

这一步的情绪很实在：表摊开了，心里有底了，剩下的是人核与回业务系统，不是继续跟模型磨洋工。桌面会话到验收为止，改原表还是回业务系统，都是人的事。

 

—坑与何时停—

  • 只存文件不贴表 → 要求贴回对话再验收
  • 总计与小计加总不符 → 以原文逐行加总为准
  • 把别的桌面夹（如报销票据）混进来 → 停，收紧文件夹名
