【公众号账号】

费用材料常按文件夹拆：差旅一夹、办公一夹、招待一夹。你要的不是再开一个聊天窗口，而是费用汇总成机器能接的 JSON，跑完进程自己退出。这正是 DeepSeek Harness headless 的场——把 AI办公嵌进脚本，而不是嵌进点击。

对照桌面点选：窗口适合看会话；批跑适合 oneshot。今晚任务：目录进 headless，stdout 出汇总 JSON，核对 grand_total。

 

—什么时候该上 headless—

要「跑完返回」时上 headless；要逛插件、看气泡时留在桌面。

  • 多个费用文件夹要周期性汇总——点选会疯。
  • 下游还要接表格/看板——需要稳定 JSON 字段。
  • CI 或定时任务调用——必须 exit，不能挂着聊。

图：费用批跑示例目录；各夹 items.txt，输出 expense_summary.json。

【广告位1】

 

—命令怎么抄、字段怎么锁—

本机 PATH 未必有全局 dsh，可用桌面版自带 cli（与 headless oneshot 篇同一套路）。进示例目录后发任务：只读 materials 下 items.txt，输出单对象 JSON，不要 markdown 围栏。

cd C:\Users\laoli\Documents\dsh-demo-headless-expense-json
dsh --profile headless "读取 materials 下各文件夹 items.txt，输出费用汇总 JSON：generated_at、folders[{name,items[{desc,amount_cny}],subtotal_cny}]、grand_total_cny；不要编造行；不要 markdown 围栏"

图：本机 headless 真终端；红框罩费用汇总 JSON 与 grand_total。

选项以本机 dsh --profile headless --help 为准；常见有 --json / --session-id。帮助里没有的旗标，今晚先别用。

 

—验收：小计加总得对上—

本机实跑 exit 0：trip-shanghai 小计 1879、office-supplies 1089、client-dinner 1988，grand_total_cny = 4956。验收就盯三件事——字段齐、小计对、总和对。

图：真跑产物用 VS Code 打开验收；红框罩 grand_total 字段。

  1. 逐夹打开 items.txt，心算或表算小计。
  2. 三个小计相加是否等于 grand_total。
  3. desc 是否只来自文件原文（高铁/酒店/硒鼓等），无新增幻想行。

【广告位2】

 

—和桌面版怎么分工—

桌面版：调提示词、看单夹对不对。headless：同一句提示词批跑、进脚本。CLI 唤不醒桌面窗口——这点和 oneshot 篇同一边界。

费用汇总进脚本前，我建议先在桌面版对一个小夹跑通字段，再原样搬进 headless。字段名一变，下游 JSON 解析就会碎。所以 AI办公批跑的稳，来自「先锁字段、再放大目录」，不是来自多开窗口。

若某夹 items.txt 编码或金额写法不统一（有的写「元」、有的只写数字），先人肉规范成「描述 + 整数金额」再批跑；模型不应被默许猜测汇率或税率。

 

—最后—

意图就一句：用 DeepSeek Harness headless 做费用汇总 JSON，服务 AI办公流水线。本机 grand_total 4956 可对上；字段锁死就能复跑。

适合要接脚本的人；只想拖文件聊天的，继续用桌面版即可。
