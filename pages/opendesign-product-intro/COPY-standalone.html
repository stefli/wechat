【公众号账号】

产品要上线，需要一段十几秒的介绍片：痛点 → 操作 → 结果。很多人第一反应是开剪辑软件，从空白时间轴硬排；或者打开某个 AI 设计工具，却在一堆「原型 / 落地页 / 升级后使用」里找不到入口。

今晚只办一件事：装好并打开 Open Design 桌面版，创作类型选 动效设计，贴一条三幕产品介绍提示词，跑通后导出可播放的短片。分两层看——先弄清它是什么，再按第一次打开的人能跟做的顺序走完。

 

—Open Design 是什么—

Open Design 是一款桌面创作 App（我实测时界面是简体中文）。它不是传统时间轴剪辑器，也不是只出静态海报的作图板。首页创作类型里，有原型、落地页等选项；要做产品介绍短片，关键入口是 动效设计——底层走 HyperFrames：用提示词写出分镜与动效，再渲染成 MP4。

因为：你描述的是「三幕卖点」而不是一帧一帧的关键帧时间码，所以适合功能讲解、流程演示这类 10～20 秒片子。不能做：长旁白口播成片、复杂实拍剪辑、替你写完整个营销方案。官方还提供 Cloud 模型通道；本机也可以接 CLI。今晚主线只跟「动效设计 → 产品介绍片」，通道怎么省额度另有专文，这里只指路、不复述。

红框附近：首页积分与升级入口；中间是创作输入区与示例卡片。

 

—材料与安装前提—

跟做前先对齐这几条。缺一条，后面步骤会空转：

  1. 本机已安装 Open Design 桌面版，能正常登录；语言可切简体中文
  2. 知道今晚要讲的产品名、一句话卖点、三幕分别是什么（痛点 / 操作 / 结果）
  3. 通道二选一已就绪：要么能用 OpenDesign 官方 Cloud；要么本机已装 Codex CLI，并经 Magpie 接到免费 DeepSeek（或等价免费路由）

提交前必须清空 composer 里的示例文案。残留示例容易被理解成第二个无关项目，多烧一轮配额。

【广告位1】

 

—打开软件，选「动效设计」—

打开 Open Design。等首页出现「让我们创建…」一类引导与中间输入区。在输入区工具条里找到创作类型下拉（常见绿字标签），点开后选 动效设计——不要停在「原型」或落地页模板上。选对后，标题区会切到动效相关引导。

红框：创作类型已切到「动效设计」。

 

—第1步：清空示例文案—

动效设计里，composer 常预填插件/示例句子。我当时没清干净，Agent 把示例习惯类 App 拼进理解，按双交付去跑；Motion 片已经出来，我才手动停止，才没继续烧本机配额。

你现在做：全选输入区 → 删掉示例 → 只留空白光标。确认工作目录指向你今晚的独立文件夹，别混进正在用的业务工程。

 

—第2步：粘贴产品介绍提示词—

一条提示词说清：时长、画幅、主题、三幕、风格、收束口号、不要旁白。下面这段是通用示例（主题可换成你的产品）；整段复制进输入区：

请用 HyperFrames 做一段约15秒、16:9 的中文动效短片：主题「示例办公工具 · 三步筛简历」。
三幕依次出现：(1) 上传简历 PDF → (2) 按岗位关键词打分筛选 → (3) 输出短名单。
风格简洁扁平、青绿配色、大标题+短字幕，节奏明快，结尾定格「三步搞定筛选」。
不要旁白音轨，不要过度花哨，不要额外做第二个无关产品。

改括号外的产品名与三幕即可；不要一次塞两个无关产品，也不要为「再好看一点」连跑多次。

红框：提示词区、动效设计标签、运行按钮——结构与跟做一致。

 

—第3步：选通道（Cloud 或本机 Codex）—

同一套「动效设计」界面，差别在 谁来当脑子。分两层看：

  • 本机有 Magpie + 免费 DeepSeek：设置 → 模型与提供商 → 本机 CLI → 选中 Codex CLI，模型跟「CLI 默认设置」。扣的是 Magpie / WorkBuddy 免费配额，OpenDesign Cloud 美元额度不动。
  • 没有本机网关：用 OpenDesign 官方 Cloud 免费档（界面芯片是官方模型名）。额度薄，适合对照与偶尔出片，不宜当天天主力。
  • BYOK 自填 DeepSeek Key：设置里对项目读写限制更严，动效写盘+渲染别拿它当主力。

我推荐：本机 Magpie 已通就走 Codex；否则先用 Cloud 跑通一次，再决定要不要接本机。Cloud 免费档怎么扣那点额度、本机 Codex 怎么指到 Magpie，各自有专文深挖——本稿只要求你在设置里看清当前芯片，别跑错路。

红框：本机 CLI 列表里选中 Codex CLI（有 Magpie 时的推荐通道）。

 

—第4步：只运行一次—

确认创作类型仍是动效设计、提示词只有一条、通道芯片正确，然后点输入区右侧的 运行。只点一次。规划首响通常几十秒量级；随后写 HyperFrames、渲染 16:9 MP4，整段可能到数分钟。底部若显示 Default (CLI config) 或官方 Cloud 模型名，用来核对你还在哪条路上。

红框：进行中状态与底部 CLI config——说明仍在本机通道。

MP4 一落地就停。若 Agent 还想开第二个无关项目，手动停止，别为「再改一版」连烧。

 

—第5步：导出与验收—

完成后，对话区会给出分镜/交付计划，工程里留下可播放 MP4（以及可二次改的 HyperFrames 源，若有）。验收只盯这几条：

  1. 时长接近提示词（约 15 秒量级），画幅 16:9
  2. 三幕顺序对：痛点/打开 → 核心操作 → 结果/收束口号
  3. 无旁白音轨（若你明确要求不要）；字幕可读、不过度花哨
  4. 通道符合预期：本机路径下 Cloud 额度不应被啃；Cloud 路径则接受小额扣减

红框：完成态与交付计划；仍可核对底部通道芯片。

关键帧1：上传简历 PDF。

关键帧2：按关键词打分。

关键帧3：输出短名单。

关键帧4：片尾定格「三步搞定筛选」。

【广告位2】

 

—我的经验教训—

我第一次跑动效，默认还停在「原型」，生成出来完全不是短片。后来养成习惯：先看创作类型是不是「动效设计」，再谈提示词。你要是也一打开就往输入框里贴长文，先抬头确认绿字标签。

第二件：composer 爱夹带示例。我栽过双交付，Motion 片出来后还在烧。现在固定动作是 清空 → 只贴一条 → 只跑一次；片落地就停。

第三件：通道看界面芯片，不看自我感觉。本机路径要在设置里真选中 Codex CLI；Cloud 路径就接受免费档很薄的现实。OD 界面不直接显示 Magpie/DeepSeek 真实费用，成本要在网关侧自己看。全流程可能到十几分钟——只想要短片时，别在渲染结束后继续追问「再炫一点」。

 

—最后—

Open Design 的动效设计，适合把「产品三步卖点」收成 10～20 秒可导出短片；不适合替代长口播成片，也不适合替代完整营销策划。

今晚跟做链：安装登录 → 选动效设计 → 清空示例 → 贴三幕提示词 → 选对通道 → 只跑一次 → 按三幕与时长验收。有 Magpie 走本机 Codex；没有就先 Cloud。通道细节去读专文，本稿只保证你找得到入口、跟得完一版产品介绍片。

改产品名与三幕，同一条提示词骨架可以反复用。卖点没写清之前，别急着连跑三版「再好看一点」。
