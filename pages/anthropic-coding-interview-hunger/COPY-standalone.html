正文

朋友群里有人甩了条标题：「Anthropic 不考编程了。」底下立刻吵开：有人说「刷题党凉了」，有人说「大厂全线改规则」，还有人问我——供应链这边招人，要不要今晚就把笔试题砍掉？

我也是老李。这种帖子最怕的不是热闹，是热闹散了你还分不清：到底是谁说的、说到哪一层。下面这几个问题，按公开博客和转述材料挨个答；答完你自己决定慌不慌、抄不抄。

先把钩子挂住：要是标题党把「一个人的面试环」写成「全公司政策」，你照着改自家招聘，亏的可不止一场面试。

 

—是不是 Anthropic 全员都不考编程了？—

不是。公开材料写的是：Anthropic 工程经理 Felix Rieseberg，作为 hiring manager，本月起在他自己的面试环里去掉传统 coding interview。他自己在 X 上也写得很窄：至少对他自己的团队（at least for my team）来说，这类题没信号了。

dotey（宝玉）的长转述把边界又钉了一遍：这说的是他自己的面试，Anthropic 全公司是否都这么做，文章没说。所以你可以——把「停考」读成一位经理的实践选择，别读成「总部红头文件」。标题党最爱吞掉主语；你把主语补回去，就不容易被带跑。

图：个人面试实践 ≠ 公司全员统一令。转述也强调了这点。

所以你可以：转发前先问一句「主语是谁」。主语是 Felix 的 loop，就别写成 Anthropic 全员。

【广告位1】

—为啥说编程题没信号了？—

因为模型把「小题」考废了。Felix 的理由很直：现在给候选人一道小 React 挑战，跟考人汇编差不多——Claude 两边都更会做。过去，快速定义问题、找优雅解，算是弱但有用的预测信号；他说那套信号已经不再成立。

他还补了一句更扎心的：团队里最能出成果的人，跟这类测试考得好不好，关系不大。翻译成人话：刷题高分，不再等于你能把业务推近一步。编程面试本来就不讨人喜欢；它要消失，老工程师会有情绪——那情绪多半冲着「角色在变」，而不只是冲着一道题。

图：小题信号失效的三段式——不是「代码不重要」，是「这种考法测不到真正出活的人」。

所以你可以：别急着说「面试全废了」。废的是小题目作为筛选器，不是「会不会把东西做出来」。能演示、能落地、能说清业务影响的人，信号可能更值钱。

 

—「冲劲胜过资历」对普通人意味着什么？—

意味着：没话语权的人，终于可以用「做出来」换注意力。文章标题叫 Hunger beats tenure。Felix 说 junior 一词不准——他其实写给没有社会资产、地位、话语权的工程师。

新人的本钱是新鲜视角，甚至是一点「无知」带来的胆：Stripe 创始人曾叮嘱新人盯着觉得别扭的地方；组织理论里也有「需要天真与无知的流入」这类说法。短板也硬：没人听你的。过去执行贵，公司靠少数几个人拍板点子；新人得先熬出地位，组织才肯押注。现在执行变便宜了——周末原型，就能跳过漫长的需求文档和 lobby。

他自己也当过反面教材：在 Notion 想装电视看板碰壁，放弃了；一年后新同事 Ji Pei 提同样想法，他劝别折腾——结果对方已经问过，第二天电视就到了。那一年里，他自己变成了「老员工」。所以你可以：别把「我试过了」当成永久否决票；也别空喊冲劲却交不出可演示物。

图：盯业务影响 → 大胆点子 → 周末原型 → 一个点子 → 用好新视角。

五条浓缩成人话：绑赚钱的业务；想一个真大胆的点子；周末做出来；原型里只放一个好点子；面向用户就用外部用户的眼睛看产品。

 

—不考题了还看什么？—

看能证明品味、同理心和有原则思考的小原型——他自己也说替代考法还没想好。这点很重要：停掉旧考法，不等于新考法已经标准化。Felix 写明：他还在摸索怎么面试「会用 AI 把东西做出来」的人；目前会扫简历和作品集，找那些小原型。

Anthropic 自己的例子也写进了文里：大家用惯了命令行版 Claude Code，是两位入职不久的工程师 Anthony Morris 和 Alice Zhao，用一个周末做出图形界面原型，大约八天后公开版上线。故事要说明的不是「周末神功」，而是——能跑的原型，比资历叙事更有说服力。

所以你可以：作品集别只堆刷题截图；留一两个「问题—做法—结果」清楚的小东西。面试官若还在考小题，你仍按对方规则准备；但你自己的长期筹码，是能演示的判断力。

【广告位2】

—供应链 / 非大厂工程人怎么用这条新闻？—

用来校准「信号」怎么读，别用来今晚改招聘制度。你我多数人不在 Anthropic 发 offer。这条新闻对供应链、制造业信息化、中小团队工程人的用处，是读法，不是照抄政策。

图：抄走读法与作品集习惯；别照抄大厂招聘政策当自家规章。

可以抄走的有四件：①读新闻先补主语——谁的实践、是否官方；②招人/自荐时多看「业务影响叙事 + 可演示原型」，少迷信单次小题；③内部提想法，优先周末做出能点开的东西，少开空会；④新人发言被挡时，用原型说话，比用职级说话便宜。

别照抄的也有四件：①别因为一篇个人博客就宣布「我们也不考了」——你的岗位画像、合规、外包约束可能完全不同；②别以为所有大厂同步停考——公开材料没这么说；③别把「冲劲」理解成加班表演——Felix 写的是出活与视角，不是熬夜时长；④别把转述帖当官方通告转发。

供应链场景更土一点：仓库对接、对账、排产看板、供应商报价比对——这些活里，「周末做出能演示的小工具」往往比「讲我刷过什么题」更能让业务方听进去。

 

—你今晚就能想明白的—

1. 打开原帖或转述时，先圈出主语：是 Felix 的面试环，还是「Anthropic 全员」——后者公开材料没写。
2. 若你在招人：今晚只加一条讨论——「我们到底在测什么信号」，先别改制度。
3. 若你在找机会：作品集里留一个「单点子、能跑、能讲业务影响」的小原型。
4. 若你在团队里没话语权：选一个绑着赚钱目标的小切口，周末做出来再说话。
5. 看见「全员不考了」类标题，默认当标题党，直到你亲眼看见官方政策页。

不被忽悠，是把主语补回去；有底气，是手里有一个能点开的东西。编程题会不会大面积消失，公开材料还没给全行业时间表——但「小题信号变弱、出活信号变强」这件事，已经够你今晚想明白。
