正文

朋友还在吵：要不要上「无限 token」套餐，还是干脆本地部署。今天晚上测了一下，没跟他抬杠，先打开 OpenCode 看菜单——DeepSeek、GLM 的 Flash，旁边标着 Free。

我是老李。结论放前头：DeepSeek V4.1 Flash Free 和 GLM-5.3-Flash Free，今天在我这台 Linux 上装好 OpenCode 2.0.30 就能点，不用先充值、不用先贴 Zen Key；同一道编码题，分别约 2.2 秒 和 6.3 秒，费用都是 $0。但这是限时免费档，官方没写截止日期——别听成永远免单。

 

—菜单上真有免费菜—

装完之后跑 opencode models，能看到一串 opencode/*-free。我这边点得着的免费档大概 12 个（含 Big Pickle）。社区有人喊「15 个全免」，口径接近，但以你本机列表为准，别写死。

真屏：OpenCode 2.0.30 · opencode models 滤出的免费档 + 本机 smoke 摘要

官方文档 Free models 节：DeepSeek V4.1 Flash Free、GLM-5.3-Flash Free 均写 limited time

安装一行（Linux／macOS 同款思路）：
curl -fsSL https://opencode.ai/v2/install | bash
装完进项目目录跑 opencode，再用 /models 选 opencode/deepseek-v4.1-flash-free 或 opencode/glm-5.3-flash-free。

【广告位1】

 

—同一道题：两个 Flash 免费档对打—

提示词很短：写一个 is_palindrome，忽略空格和大小写，带一条 doctest，只要代码。工作目录是 /home/laoli/projects/oc-smoke/。

Write a Python function is_palindrome(s: str) -> bool that ignores
spaces and case. Include one doctest. Reply with code only.

DeepSeek V4.1 Flash Free：约 2160 ms，cost $0，tokens 大约 in128 / out71。代码干净，能跑。
GLM-5.3-Flash Free：约 6280 ms，cost $0，tokens 大约 in1022 / out73（想得稍长一点）。代码也对。

本机 OpenCode 会话导出对照：左 DeepSeek Free 2.16s／$0，右 GLM Free 6.28s／$0

本机 Web 会话列表示意（工作目录 /home/laoli/...）。会话正文 UI 未截全，以终端与导出代码为准

 

—免的是哪堵墙—

今天这趟：没登录 OpenCode Console，也没贴 Zen API Key，免费档照样回了。所以朋友说的「模型墙」，至少付费门槛这堵，先矮了一截。

但别高兴太早——拿 curl 直接打公开接口，会吃到 403 FreeTierError，官方意思很清楚：免费档只能从 OpenCode 客户端里用。「免模型墙」更像「免单独找 Key／免先充值」，不是谁都能无限刷公共 API。

付费同名 Flash 文档价（每百万 tokens，当日）：GLM 5.3 Flash 约 $0.15 / $0.50；DeepSeek V4.1 Flash 约 $0.30 / $1.20（输入／输出）。免费档写着 limited time，以前的 deepseek-v4-flash-free 已经下过桌——限时结束就可能掉回付费价或直接消失。

 

—和「无限 token／本地部署」怎么放—

无限套餐：适合已经认准一家、愿意按月付钱的人。
本地部署：隐私和可控更强，但机器、显存、升级你自己扛。
OpenCode 这桌免费自助餐：先把活干了，限时结束再决定要不要付费 Flash，或换本地。三件事不互斥，看你今天急不急交差。

【广告位2】

 

—缺点直说—

① 限时，官方没写截止日期；别当永久福利。
② 免费模型不全是「零保留不训练」：DeepSeek／GLM Free 文档写零保留；Big Pickle、MiMo、Nemotron、LL Alpha、Muse Contributor 等可能拿数据做反馈或另有条款——机密代码别往里扔。
③ Cat Jam Free 文档写对中国（含港澳）等地不可用。
④ GLM 免费档我第一次编码会话曾卡住只见提问不见回复，重开后正常——偶发，不写成配额墙定论。
⑤ Web 会话正文界面这次没截全；证据以 CLI 列表、官方文档节、会话导出代码卡为准。

 

—一句话：限时自助餐，趁热夹两筷子—

OpenCode 2.0.30 + DeepSeek V4.1 Flash Free／GLM-5.3-Flash Free：装好就能点，同题编码约 2.2s／6.3s，费用 $0。免的是付费门槛，不是永远免单，也不是裸 curl 随便刷。朋友要是还在纠结无限套餐还是本地，先让他夹两筷子再说。
