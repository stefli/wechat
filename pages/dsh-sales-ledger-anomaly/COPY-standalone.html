【公众号账号】

月底盯 销售台账 最烦的不是公式，是那几行「看起来不对」。今晚打开 DeepSeek Harness 桌面版，让办公 Agent 先标异常、再算环比。

卡点很具体：表在桌面「销售台账示例」，异常仍靠感觉。任务就一件——读 CSV、标异常行、给出环比，数字只许引用原表。

下面按现场顺序：材料摊开 → 桌面新会话 → 粘提示词 → 产物核对。

 

—材料放桌面—

示例放在桌面 销售台账示例。表头是月份、区域、SKU、数量、金额。华北一条数量从 85 跳到 210，华东同月同 SKU 多出 qty=5。

  1. 一张 CSV：sales_ledger_2026Q3Q4.csv
  2. 先自己瞄一眼华北 B07、华东 A12，心里有数再开 DSH
  3. 文件夹放桌面，名字就叫「销售台账示例」

红框：桌面「销售台账示例」文件。

材料认清之后，先别急着点发送。桌面版跟命令行最大的差别，就是你能看见输入框、发送键和回复区——照着点就行，像教同事用办公软件。跟做前先确认 DeepSeek Harness 桌面窗能打开、能新建会话；提示词整段复制即可，不用自己改写口径。

【广告位1】

 

—桌面里怎么点—

打开 DSH 桌面版 → 点 新会话 → 说明材料在桌面「销售台账示例」→ 粘贴提示词 → 发送。

请读取桌面上的「销售台账示例」文件夹里的 CSV。

任务：标出异常行，并给环比结论。
输出：
1）异常行表：行号或日期｜SKU/品名｜异常类型｜原值｜说明
2）环比摘要：按月金额/数量环比（只引用表内数字）
异常类型只用：金额突增／金额突降／数量异常／缺字段／其他。
数字只许引用原文，禁止编造。用 Markdown 直接回复。不要改原始文件。

不要让它把疑似重复静默并进合计；环比分母必须说清是否含重复行。

红框：桌面主区——异常与环比提示词已粘贴。

 

—产物怎么验收—

桌面真跑后：华北 SKU-B07 数量 85→210，环比约 +147%；华东 SKU-A12 同月另有 qty=5，标成疑似重复。所以你下次可以：先自己瞄可疑行，再对照清单。

红框：桌面主区异常表与环比摘要。

验收时只盯你关心的那几格数字。表好看不重要，对得上原文才重要。桌面主区能看见的内容，这篇才算跟做完成。交稿前再问两句：数字能不能在原文件找到？需人核的行有没有留着？两句都过，这篇才算落地。

【广告位2】

这一步的情绪很实在：表摊开了，心里有底了，剩下的是人核与回业务系统，不是继续跟模型磨洋工。桌面会话到验收为止，改原表还是回业务系统，都是人的事。

 

—坑与何时停—

  • 原表被改写 → 停，回备份
  • 无穷大环比 → 标新增
  • 只有金额跳、数量平 → 查单价单位

 

—最后—

普通人跟做时记住：桌面主区能看见的表，才是验收对象；示例公司数据只用来对照步骤，换成你自己的材料时，提示词里的文件夹名一并改掉。路径对外只写桌面文件夹名。

AI办公 里，销售台账适合桌面先标异常；不适合直接覆盖原表。DeepSeek Harness 帮你摊开，你来决定删哪一行。

你今晚跟做：桌面新会话 + 上面提示词，验收只盯跳升与疑似重复。
