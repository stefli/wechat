【公众号账号】

朋友把一条帖转给我：DeepSeek Flash 一句 prompt 就能出片。听起来像文生视频又砍掉一截门槛——模型便宜、上下文大，社区还晒出两分钟游戏史预告风的硬片。

今晚要办成的事很具体：用 Flash 真走一遍最短刀口，看它吐出来的「片」到底是什么，以及你照做时卡在哪一步。

先把常见说法顺着捋半截。再对照实测，看公开材料和本机产物里真正要紧的那一句。

—听起来像「一句话出片」—

公开材料里，Flash 的定位是语言模型写代码：社区典型 demo 是一句 prompt，吐出 HTML / Canvas / WebGL / SVG 单文件，浏览器里播放，再录成 MP4。模型版本对外写作 DeepSeek-V4.1-Flash-1017，API 名 deepseek-flash（旧名仍可调，实际由 1017 承接）。

社区里有两条常被拿来对照的路径。一条是 NFT_Chen 那类：一句 prompt，要求纯代码生成约 2 分钟、1920×1080、60fps 的「电子游戏史」纪录片预告风，配乐也要求代码合成、禁外部素材——原帖没有公开精确 prompt，社区有近似复现。另一条是花叔路径：Claude Code 接 DeepSeek 的 Anthropic 兼容接口，再挂上 huashu-motion 一类 skill，带 skill 时可以走到带配乐的 MP4 编辑流。

如果只停在这一层，结论很容易写成：Flash 很强，「一句 prompt 出片」已经成立。这一层没有错，只是还没把「片」这个字钉死。

【广告位1】

—真正要紧的是：吐出来的是代码—

拧过来的那一句是：出的是代码动画 / 网页片，不是 Sora 类像素视频一次生成。模型本身不渲染成片像素；浏览器打开 HTML 才「看得见片」；要发平台，还得录屏或无头导出。

所以本篇刀口刻意收窄：

  • 不硬扛 NFT_Chen 那条两分钟游戏史——原帖无精确 prompt，复现成本不在今晚。
  • 不走花叔 skill 全链路——那条路径成立，但依赖本机 Node / Chrome / FFmpeg 与 skill 本身。
  • 只验收纯 API 一句 prompt → 单文件 HTML → 浏览器可播。

主题选「老李周报痛点」约 18 秒竖屏动效：纸片砸落 → 收成「一句 prompt」细线 → 收束芯片写清边界。配色只留纸白、深墨、DeepSeek 蓝。

· · ·

—材料准备—

跟做前先把材料放进同一个文件夹，路径示例：C:\Users\laoli\projects\laoli-demo-deepseek-flash-prompt-video\。

  • 本机 Magpie 网关已接通 DeepSeek 供应商（chat / responses / anthropic 预检通过）。
  • 模型 id 指向 deepseek-flash（Magpie 侧常见写法 deepseek/deepseek-flash）。
  • 准备一个空的输出文件夹，用来落 HTML 与截帧。
  • max_tokens 留足：思考模式会吃掉大量 completion_tokens，太小容易把 HTML 截断。

没有 Magpie 也行：官方 Anthropic 兼容接口可以把 ANTHROPIC_MODEL=deepseek-flash 接到 Claude Code；本篇实测走的是 Magpie 本机网关。

—第1步：确认模型指向 deepseek-flash—

打开你平时调模型的入口，确认当前会话或默认模型已经指向 deepseek-flash，而不是别的长思考默认项。供应商测通后再开新请求，避免旧会话还握着旧模型。

—第2步：贴这段提示词—

下面整段原样复制。意图写死：单文件、Canvas 2D、约 18 秒竖屏、三段节奏、无外链、只输出 HTML。

红框：可复制的完整提示词正文

做一个单文件 HTML，用 Canvas 2D 画一支约 18 秒、竖屏 1080×1920 的「老李周报痛点」动效片。
要求：
1. 不使用任何外部库、图片、字体、音频文件；全部纯代码。
2. 打开页面即自动播放，循环；用 requestAnimationFrame。
3. 三段节奏（约各 6 秒）：
   A. 周五傍晚：一堆「周报.docx」纸片从屏幕上方砸下来，字越大越慌；
   B. 中间拧转：纸片收成一条「一句 prompt」细线；
   C. 收束：画面中央出现「代码动画 · 不是像素视频」芯片，副标「Flash 写 HTML，浏览器再录」。
4. 配色克制：纸白底 #F8FAFC、深墨字 #0F172A、唯一强调色 DeepSeek 蓝 #4D6BFE；禁止红黄绿乱撞。
5. 字要大、可读；动效只做淡入上移与纸片下落，不要花哨粒子风暴。
6. 输出且只输出完整 HTML（含 <!DOCTYPE html>），不要 markdown 围栏，不要解释。

—第3步：等它吐完整 HTML—

发出去之后先别急着截半截。验收点只有一个：回复是否以 <!DOCTYPE html> 开头、以 </html> 收束，中间有 Canvas 与 requestAnimationFrame。

本机这次墙钟 120.61 秒（约 2.0 分钟），finish_reason 为 stop，没有 length 截断。usage：prompt_tokens 302（cache hit 128 / miss 174）；completion_tokens 22193，其中 reasoning_tokens 约 19303；total_tokens 22495。干净 HTML 约 7286 字节。

费用按空闲价粗算是几分钱级（输出按量计，reasoning 计入输出）；精确以平台账单为准，正文不写死账单数字。

—第4步：存成单文件，浏览器打开—

把模型吐出的 HTML 存成例如 laoli_weekly_pain_18s.html，用浏览器直接打开。打开即应自动播放并循环。若前面夹了 markdown 围栏或解释前言，先剥掉再存。

红框：首屏「周报.docx」纸片砸落段

—第5步：按三段节奏验收—

对照提示词里的 A / B / C，逐段看：

  1. 纸片砸落是否可读、字号层次是否传达「慌」；
  2. 中段是否收到「一句 prompt」细线；
  3. 收束芯片是否清楚写着「代码动画 · 不是像素视频」，副标是否点明「Flash 写 HTML，浏览器再录」。

红框：中段拧转——纸片收成「一句 prompt」细线

红框：收束芯片「代码动画 · 不是像素视频」整句可读

本机验收清单再勾一遍：含 1080×1920、纸白底 #F8FAFC、强调色 #4D6BFE、无外链 src/href。要发短视频平台，还差一步：浏览器录屏或无头导出成 MP4——本篇到「可播网页片」为止，未宣称已导出成片文件。

【广告位2】

—诚实边界，写进跟做清单—

最怕踩的红线：不要把代码动画写成「文生视频模型」或「对标 Sora」。帖子标题可以喊出片，你跟做时要把产物类型说清楚。

  • 纯 API 一句，保证到的是 HTML；MP4 是浏览器之后的事。
  • 花叔「一键直出」背后有 skill 与本机工具链；对照时把路径拆开看。
  • 两分钟硬片可以当灵感，不要在没有精确 prompt 的情况下硬扛复现。
  • 思考模式会吃 token：max_tokens 不够，HTML 会断在半截。

—我的经验教训—

我当时也差点顺着标题把「出片」理解成像素视频。后来打开产物才发现：文件夹里是一份 .html，片感来自浏览器渲染。你要是也想今晚交差，先把「能不能在浏览器里循环播放」当成第一验收，再谈录屏。

第二件：reasoning 占比很高时，别只盯墙钟焦虑。先看 finish_reason 是不是 stop，再看文件头尾标签是否齐全。半截 HTML 比慢两分钟更浪费时间。

第三件：社区炫技片和今晚刀口不是同一难度。短主题、竖屏、三段节奏，足够验证链路；想上花叔那条，再单独备 skill 与导出环境。

—最后—

结论钉在一句：Flash 一句 prompt，真能吐出可打开的竖屏动效页；那是代码动画，浏览器再录才成视频文件。吹法可以保留半截热情，跟做时把产物类型说清，就不容易被标题带着跑。

适合今晚就试的人：已经能调通 DeepSeek API 或 Magpie，想验证「出片」帖到底交付什么。不适合的预期：把本篇当成 Sora 替代方案，或要求两分钟游戏史无损复现。
