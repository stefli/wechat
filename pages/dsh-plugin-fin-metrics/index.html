【公众号账号】

财报摘录一厚段，真正要盯的往往就几个数：营收、净利、毛利率、现金流。今晚打开 DeepSeek Harness 桌面版，按指标卡口径把数摘出来。

卡点很具体：手抄进幻灯片时单位容易混。任务就一件——读「财报摘录示例」，出一张可对回原文的关键指标卡。

下面按普通人跟做写：材料认清 → 桌面新会话 → 粘提示词 → 核对六格数字。

 

—材料放桌面—

示例放在桌面 财报摘录示例：一段示例科技 2026 年三季报摘录文本。没有的指标不要编。

  1. earnings_excerpt.txt：营收 / 净利 / 毛利率 / 现金流等原文句
  2. 先自己扫一眼数字，再开 DSH 对照
  3. 文件夹放桌面，名字就叫「财报摘录示例」

红框：桌面「财报摘录示例」摘录文本。

材料认清之后，先别急着点发送。桌面版跟命令行最大的差别，就是你能看见输入框、发送键和回复区——照着点就行，像教同事用办公软件。跟做前先确认 DeepSeek Harness 桌面窗能打开、能新建会话；提示词整段复制即可，不用自己改写口径。

【广告位1】

 

—桌面里怎么点—

打开 DSH 桌面版 → 点 新会话 → 若你装了财报指标插件，先在会话里启用；没装也没关系，直接粘贴下面提示词，按同一口径跑。

请读取桌面上的「财报摘录示例」文件夹里的摘录文本。

任务：整理成一张「关键财务指标卡」。
列：指标名｜数值｜单位｜期间｜原文摘录
常见指标优先：营收、净利润、毛利率、经营现金流（原文没有的不要编）。
用 Markdown 表格直接回复。不要改原始文件。

单位必须跟原文走；原文写「万元」就不要擅自改成「元」。缺字段标 原文未给。

红框：桌面主区——财报指标卡提示词已粘贴。

 

—产物怎么验收—

桌面真跑后：营业收入 12840 万元、归母净利 1560 万元、毛利率 31.5%、经营现金流 890 万元。研发与负债率若原文有，可附在补充行，但不许编。

红框：桌面主区指标卡数字行。

验收时只盯你关心的那几格数字。表好看不重要，对得上原文才重要。桌面主区能看见的内容，这篇才算跟做完成。交稿前再问两句：数字能不能在原文件找到？需人核的行有没有留着？两句都过，这篇才算落地。

【广告位2】

这一步的情绪很实在：表摊开了，心里有底了，剩下的是人核与回业务系统，不是继续跟模型磨洋工。桌面会话到验收为止，改原表还是回业务系统，都是人的事。

 

—坑与何时停—

  • 单位被改写 → 停，回原文核对
  • 原文没有的指标被补齐 → 删掉或标原文未给
  • 把指标卡当成投研结论 → 停，今晚只摘数

 

—最后—

普通人跟做时记住：桌面主区能看见的表，才是验收对象；示例公司数据只用来对照步骤，换成你自己的材料时，提示词里的文件夹名一并改掉。路径对外只写桌面文件夹名。

用 DeepSeek 桌面会话做轻量财报摘数：装插件更好，不装也能跟做。AI办公 值不值，就看六格数字能不能对回摘录。
