【公众号账号】

财报 PDF 一厚叠，真正要盯的往往就几个数：营收、净利、毛利率、现金流。手抄进幻灯片，抄着抄着单位就混了。今晚不写企业级「智能研报」，只做一个 DeepSeek 插件：粘贴摘录 → 财报分析指标卡。算 AI办公插件里很小、但管用的一块。

坑在哪？一上来就想接全文 PDF 解析、对接行情——那是另一条深水。我们把范围缩到：摘录文本进，六格卡出，缺项写「未披露」。

 

—插件骨架长什么样—

目录先于魔法。本地建 plugins/fin-metrics/：package.json 声明名字与入口，src/index.ts 负责抽字段，README 写清输入输出。别吹微服务集群；这就是桌面 DSH 能装的小插件。

图：DeepSeek 插件骨架 fin-metrics；红框对准抽字段入口。

plugins/fin-metrics/
├── package.json
├── src/index.ts   # 粘贴摘录 → 指标卡

【广告位1】

 

—怎么装进 DeepSeek Harness—

装法跟首批插件篇同一心智：看清是 plugin 层，不要塞错 profile。开发态把插件目录指到 DSH 可加载位置（以你当前版「管理插件 / 本地插件」入口为准），重载后再开新会话验收——旧会话可能还握着旧工具列表。

  1. 确认 package.json 的 name/version/main 可读。
  2. 在 DSH 插件页能看到 fin-metrics（或本地列表命中）。
  3. 新会话粘贴摘录，看是否走出指标卡而不是普通闲聊。
粘贴 earnings_excerpt.txt 全文。
用 fin-metrics 插件抽出：营收、归母净利、毛利率、经营现金流、研发、负债率。
只引用摘录数字；缺项标「未披露」。不要编造市值或未出现的同比。

图：本机真跑产物用 VS Code 打开；红框罩产物表/摘录对回。六格指标卡见下一张。

 

—验收指标卡—

示例摘录取数：营收 12840 万（同比 +18.2%）、归母净利 1560 万（+6.4%）、毛利率 31.5%（上季 30.1%）、经营现金流 890、研发 2140、负债率 42.8%。卡上数字必须能在摘录里指回；多出来的「解读段」可删。

红线：只引用摘录；没有的同比别补齐。

【广告位2】

 

—边界：别吹企业级—

这是个人/小组 AI办公插件：加速摘数，不是投研平台。不做权限审计、不做多租户、不对接交易所。PDF 扫描件、图片表，需要你先转成可粘贴文本——插件不承诺 OCR 全自动。

  • 能做：摘录→指标卡、缺项标注。
  • 不能做：自动研报结论、股价预测、替代披露合规。
  • 停手：模型开始补「分析师一致预期」——超出摘录就打断。

插件开发写到这里就够交差：骨架清晰、能装进 DeepSeek Harness、指标卡可对回摘录。再往上堆「自动估值模型」属于另一篇文章，也更容易吹过头。财报分析在桌面 Agent 上的正确姿势，是先把数摘对，再谈观点。

若你要复用给同事：把 plugins/fin-metrics 连同示例摘录一起打包，并在 README 写明单位（万元）与「未披露」规则，避免每人提示词各写一套。

 

—最后—

用 DeepSeek 插件做轻量财报分析：骨架装进 DeepSeek Harness，验收看六格卡是否都有摘录出处。小而真，胜过空而大。

适合自己要做摘录卡片的读者；要做投研工作流的，另开专题。
