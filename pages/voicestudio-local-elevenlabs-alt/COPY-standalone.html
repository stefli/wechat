【公众号账号】

竖屏旁白一开口就撞墙：云端 TTS 按字计费，长一点的稿子试两遍账单就上来；人声录一遍又要降噪、对齐字幕。想把旁白轨留在本机，却不知道从哪一步点进去。

今晚要办成的事很具体：打开本机 VoiceStudio 当前桌面版，过完系统检查与模型包，进工作室设计页，用默认引擎冒烟生成一句旁白，拿到能进 Remotion 旁白轨的本地音频。

磁盘不够会不会卡死「继续」？隐私页只点继续会不会原地打转？这两处我当场踩过——按下面顺序跟，比空讲概念快。

—材料准备—

先把东西放齐，再开软件：

  • 本机已装 VoiceStudio 当前桌面版（官网 voicestudio.sh / download；仓名 debpalash/VoiceStudio）。
  • 建议内存 16 GB+；模型首次下载大约要数 GB 到十余 GB 空盘。
  • 数据目录可用 C:\VoiceStudioData；系统盘紧张时迁到大容量盘，再用目录联接指回原路径。
  • 旁白稿先备一句（约数秒到十余秒口播量即可冒烟）；商用参考音只用已获授权或自录。

我今晚冒烟用的旁白稿如下，可直接复制：

今晚这条竖屏旁白，我在本地 VoiceStudio 生成，不走云端计费。

【广告位1】

—打开软件，先过系统检查—

启动 VoiceStudio。首次或数据目录变动后，会先落在系统检查。左侧四步：系统检查 → 模型包 → 隐私 → 进入工作室。

磁盘不够时，「一切正常 — 继续」会灰掉。我本机系统盘一度不够模型缓存，Continue 点不动。把数据目录迁到大容量盘，并用目录联接保持 C:\VoiceStudioData 可读后，预检全绿，可用空间显示到百 GB 量级，右下角蓝色继续才可点。

图：系统检查全绿。红框：磁盘可用空间一行；右下「一切正常 — 继续」。

—第1步：模型包选均衡，确认 TTS 已装—

点继续进入模型包。预设里选均衡即可冒烟。本机卡片显示 VoiceStudio TTS（k2-fsa / OmniVoice）状态为已安装；其余 ASR / 听写模型可按需再下，不挡今晚出旁白。

默认引擎是 OmniVoice，权重条款与 CosyVoice 不同——公开材料里 OmniVoice 预训练常见 CC-BY-NC，商用旁白不要默认「装上就能卖」。本站竖屏旁白硬规则优先 CosyVoice2：要对齐 Remotion，进工作室后在 Model Manager 再换 CosyVoice 系；本次冒烟未截到 CosyVoice 选中态，下文用文字说明，不拿默认引擎冒充已对齐。

图：模型包 · 均衡。红框：OmniVoice TTS 已安装；右下继续。

—第2步：隐私页必须先选一项—

进入隐私步。上面两行选项：是，分享匿名统计 / 不用了，谢谢。我选后者。

只点右下「继续」、不先选统计意向，会停在隐私页。选完一项，再点「一切正常 — 继续」，才能进工作室。页面里的不可见水印默认开着，会把后续生成音频标成 AI 制作，按需再关。

图：隐私。红框：「不用了，谢谢」；再点继续。

—第3步：进工作室，选叙述者起点—

点「进入工作室」。设计页中间是音色描述与起点列表。今晚冒烟选叙述者；新闻主播、商务等可后换。左侧状态应显示本地引擎已就绪；速度/质量滑条可放在均衡。

右侧文本区清空后，粘上刚才那段旁白稿。不急着追求长稿——先确认「生成音频」能跑通。

—第4步：点生成音频，看波形与时长—

点右下生成音频。完成后，波形下方会给出时长、渲染耗时与采样率。本机这句旁白的真屏读数是：5.2s · 在 0.6s 中渲染 · 24 kHz。另存为即可落盘；需要脚本批量时，本机常见还有 http://localhost:3900 的 OpenAI 形 /v1/audio/speech，可直接出 WAV。

图：工作室设计页生成完成。红框：旁白稿、时长条、生成音频。

—怎么验收—

对照这三项，才算今晚刀口跑通：

  1. 系统检查全绿，继续可点；磁盘路径指向你的数据目录（可写 C:\VoiceStudioData）。
  2. 模型包里 TTS（默认 OmniVoice）为已安装；隐私页已先选统计意向再继续。
  3. 设计页波形出现，UI 给出时长与渲染耗时；文件可另存。需要进 Remotion 时，把该 WAV 当作旁白轨素材；本站竖屏旁白优先 CosyVoice2——要对齐，再到 Model Manager 换引擎后重出一版，进 Remotion 后清缓存、字幕跟本版音频重建。

【广告位2】

—边界先抄走这三条—

  • 应用许可 ≠ 模型许可。应用常见 AGPL-3.0；各引擎权重另有条款。Model Manager 会展示——OmniVoice 预训练常见 CC-BY-NC；CosyVoice2 上游常见 Apache-2.0，仍以卡片为准。
  • 只克隆有授权或自录的参考音。本地跑不等于免责；未授权名人 / 同事声不要碰。
  • 首次下模型占盘、耗时。有独显更快；无独显可冒烟但更慢。本地 OSS 无需 ElevenLabs 式云 API Key，但更新检查与用户触发的模型下载会触网。

—我的经验教训—

第一件：系统盘剩几 GB 时，别急着怪软件卡死。我当时 Continue 怎么点都没反应，后来才发现是模型缓存盘不够；迁到 C:\VoiceStudioData 对应的大容量位置并做好联接，预检立刻全绿。

第二件：隐私页的「继续」和上面的统计意向是两道门。我第一次只点继续，界面纹丝不动；先点「不用了，谢谢」再继续，才进工作室。你要是卡在同一步，先看上面有没有选过。

第三件：默认 OmniVoice 冒烟很快，但不等于 Remotion 旁白链路已经对齐。本站竖屏旁白硬规则仍是 CosyVoice2——今晚先证明本地能出 WAV，下一步再换引擎，别把两件事揉成一句「已经平替完了」。

—最后—

结论钉在一句：本机 VoiceStudio 过完系统检查、模型包与隐私选择，设计页就能用默认引擎冒烟出旁白；时长与渲染耗时以真屏为准，WAV 可进 Remotion 旁白轨。要对齐本站竖屏旁白硬规则，再换 CosyVoice2 系重出一版。

适合今晚就试的人：已经装好桌面版、想先摆脱云端 TTS 账单试一句旁白。不适合的预期：把默认 OmniVoice 直接当成可商用旁白方案，或要求本篇覆盖整条短片成片。
