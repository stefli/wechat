正文

朋友说产品介绍片要请人做动效，一听报价就皱眉：「是不是得上最贵的模型才出得来？」今天晚上我没跟他抬杠，直接打开 Open Design 0.25.0，走的是官方 Cloud 免费档——不是本机另一条 CLI 路线。

我是老李。结论先说：设置里选 OpenDesign（官方推荐），模型用 v4.1-flash（界面写着 OpenDesign · deepseek-v4.1-flash），创作类型切到动效设计，一次跑通约 15 秒、1920×1080 的中文产品动效 MP4；Cloud 免费额度从 $0.50 → $0.43，花了大约 7 美分，墙钟大概 6 分钟。片子观感我挺满意，后面给产品做介绍片，这条官方免费通道可以再挖。

 

—先搞清楚：走的是官方 Cloud，不是本机另一条路—

Open Design 里能挂好几条执行通道。这篇只测官方 Cloud 免费额度：设置 → 模型与提供商 → 本机 CLI 卡片里，点选 OpenDesign（官方推荐），看清套餐是 Free、模型下拉是 v4.1-flash。首页芯片也应显示官方这条，而不是别的 CLI 默认项。

另有一条走本机 CLI 的免费玩法，我另开一篇写。这篇正文只讲官方 Cloud 免费档，别混着看。

红框①：OpenDesign 官方推荐 + Free；红框②：模型 v4.1-flash

 

—创作类型切到「动效设计」—

回到首页，把创作类型从默认的原型之类，改成 动效设计。输入框占位会跟着变成动效相关提示，别漏这一步——类型不对，后面提示词再漂亮也容易跑偏。

绿胶囊「动效设计」就是入口，红框标的就是它

【广告位1】

 

—提示词怎么写，我原样贴给你—

我要的是一支「OpenDesign Cloud 一键出片」主题的短片：三幕——输入提示词 → Cloud 生成中 → 导出 MP4；扁平、蓝紫、大标题短字幕，结尾定格「一键出片」，不要旁白。粘贴前最好在输入框里全选清空一次，避免重复粘贴（我这次同文贴了两遍，不过只点了一次运行，Agent 仍按同一主题交付）。

请用 HyperFrames 做一段约15秒、16:9 的中文产品动效短片：主题「OpenDesign Cloud 一键出片」。三幕：(1) 输入一句话提示词 → (2) Cloud v4.1-flash 生成中 → (3) 导出 MP4 成片。风格简洁扁平、蓝紫配色、大标题+短字幕，节奏明快，结尾定格「一键出片」。不要旁白音轨。

红框：提示词正文 / 动效设计 / 右下角运行按钮

 

—大约 6 分钟，官方通道把片交出来了—

点运行之后，左侧会看到 OpenDesign 在干活——规划、写 HyperFrames 源码、再导出 MP4。我这次墙钟大约从点运行到额度刷新，落在 6 分钟 左右；中间没有二次生成。

红框标的是 OpenDesign 官方通道状态区

结果页右侧能直接预览成片画面。画布上那张「做一支 15 秒的产品短片」卡片底部，清楚写着 Cloud v4.1-flash——这就是官方 Cloud 免费档这条线的证据，不是别的通道冒充的。

红框：成片卡片底部的 Cloud v4.1-flash 字样

 

—成片抽帧：提示词进，一键出片定格—

导出文件约 15.0 秒，1920×1080，H.264。我从片子里抽了三帧：开头「说一句话，剩下的交给云」、中段「Cloud v4.1-flash 生成中」、结尾定格「一键出片」。蓝紫扁平、节奏干脆——做产品介绍片的底子够用。

左约 1s / 中约 7s / 右约 14s，对应三幕节奏

 

—额度账单：诚实说，花了大约 7 美分—

生成前，设置页 Cloud Free 额度是 $0.50；生成后再看，变成 $0.43。顶部那个积分数字这次没动，扣费体现在 Cloud 美元额度上。所以别只盯积分——要确认走的是官方免费额度，就看设置页这笔账。

红框：Free + 额度 $0.43；模型仍是 v4.1-flash

免费额度会变，别当成永远免单。高级 Cloud 模型有的要升级才开；本次刻意只用免费档 v4.1-flash。

【广告位2】

 

—缺点直说—

① 免费额度就那么多，一支 15 秒片大约 7 美分，多跑几支也会见底。
② 输入框容易重复粘贴，提交前建议全选清空。
③ 规划段 UI 会先报一段「已完成」秒数，别跟整段墙钟搞混——整段从点运行到可看片，我这边大约 6 分钟。
④ 成片质量够产品介绍片试用，但复杂剧情、强品牌定制，还得自己改源码或加人工。
⑤ 本机另一条 CLI 免费路线这篇不展开，避免两条路揉成一篇糊弄读者。

 

—一句话：官方免费档，够你先出一支介绍片—

Open Design 0.25 + 官方 Cloud Free（v4.1-flash）：动效设计一次出 15 秒 1080p MP4，额度 $0.50→$0.43，大约 6 分钟。不用先上最贵模型，也能交差一支能看的产品动效。你要是也在为介绍片发愁，先把设置切到 OpenDesign 官方 Free，按上面步骤跑一支试试。
