【公众号账号】

朋友丢过来一句：「台账按月一个 CSV，每次做 月度看板 都要手贴柱状图。」我说别贴了——打开 DeepSeek Harness 桌面版，扫本地目录直接出看板。

卡点很具体：三个月文件分开放，趋势和结构靠眼估。任务就一件——读「台账看板示例」，出按月汇总与环比结论。

下面按普通人跟做写：材料认清 → 桌面新会话 → 粘提示词 → 核对月度合计。

 

—材料放桌面—

示例放在桌面 台账看板示例：2026-08 / 09 / 10 三份月度 CSV。原文件只读，不许改写。

  1. 2026-08.csv / 2026-09.csv / 2026-10.csv
  2. 先自己加总三个月金额，心里有底再开 DSH
  3. 文件夹放桌面，名字就叫「台账看板示例」

红框：桌面「台账看板示例」三月 CSV。

材料认清之后，先别急着点发送。桌面版跟命令行最大的差别，就是你能看见输入框、发送键和回复区——照着点就行，像教同事用办公软件。跟做前先确认 DeepSeek Harness 桌面窗能打开、能新建会话；提示词整段复制即可，不用自己改写口径。

【广告位1】

 

—桌面里怎么点—

打开 DSH 桌面版 → 点 新会话 → 若装了台账看板插件，先启用；没装就直接粘贴下面提示词，按同一口径扫目录。

请读取桌面上的「台账看板示例」文件夹里的月度 CSV。

任务：扫本地台账，出一屏「月度看板」。
输出：
1）按月汇总表：月份｜笔数｜金额合计
2）环比／结构一句话结论（只引用表内数字）
3）异常月（若有）单独点名
用 Markdown 直接回复。不要改原始文件。

勿改 CSV 写进提示词；类别名不统一时先在表侧统一，再扫目录。

红框：桌面主区——月度看板提示词已粘贴。

 

—产物怎么验收—

桌面真跑后：金额从 3740→5020（约 +34.2%）→4956（约 −1.3%）。差旅权重最大；10 月办公 1089 偏离前两月区间，值得点名。

红框：桌面主区按月汇总与环比结论。

验收时只盯你关心的那几格数字。表好看不重要，对得上原文才重要。桌面主区能看见的内容，这篇才算跟做完成。交稿前再问两句：数字能不能在原文件找到？需人核的行有没有留着？两句都过，这篇才算落地。

【广告位2】

这一步的情绪很实在：表摊开了，心里有底了，剩下的是人核与回业务系统，不是继续跟模型磨洋工。桌面会话到验收为止，改原表还是回业务系统，都是人的事。

 

—坑与何时停—

  • 原 CSV 被改写 → 停，回备份
  • 类别名被「智能合并」写回文件 → 停
  • 把看板当成审计意见 → 停，仍以 CSV 加总为准

 

—最后—

普通人跟做时记住：桌面主区能看见的表，才是验收对象；示例公司数据只用来对照步骤，换成你自己的材料时，提示词里的文件夹名一并改掉。路径对外只写桌面文件夹名。

本地台账目录进 DeepSeek 桌面会话，一屏月度看板；这是务实的 AI办公 用法——扫得动、对得上、改不了原表。
