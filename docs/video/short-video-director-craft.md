# 短视频导演手艺备忘录

> 受众：Justin Li（设计向）— 实拍短片 + Remotion 类程序化短片通用  
> 用途：像导演一样控片，不当「只会剪素材的人」  
> 原则：每条技法写清「干什么 / 短片怎么用 / 慎用」；实拍 ↔ 动效对照用一句带过

---

## 1. 结论先行：短片导演其实在控什么

短片不是「把好看的镜头串起来」。导演在控四件事：

| 控制项 | 一句话 | 观众感知 |
|--------|--------|----------|
| **节奏** | 信息出现与切镜的节拍 | 快/慢、紧/松、会不会腻 |
| **注意力** | 每帧让人看哪、何时换焦点 | 跟不跟得上、会不会走神 |
| **信息密度** | 单位时间塞多少可消化内容 | 懂了还是懵了 |
| **情绪弧** | 开场→钩子→高潮→落地的情绪曲线 | 想不想看完、记不记得住 |

**实操优先级（短片够用）：**

1. **先定信息落点** — 这一镜观众要带走什么一句话？没有落点就别开拍/别开写。
2. **再定注意力路径** — 景别、构图、运动、字锤，全是「把眼带到落点」。
3. **再用节奏塑形** — 前 3 秒钩、中段稳、高潮加速、结尾停一下。
4. **情绪是结果不是起点** — 光色、音乐、留白是放大器；信息与注意力对了，情绪才立得住。

**实拍 vs Remotion：** 实拍用机位/运镜/切镜控注意力；代码片用 scale/pan/cut/stagger/字锤做同一件事。控的对象不变，工具换了。

## 2. 镜头语言核心词表

### 2.1 景别

| 中文名 | 常见英文 | 干什么用 | 短片怎么用一句 | 慎用 |
|--------|----------|----------|----------------|------|
| 大远景 | Extreme Wide / EWS | 交代环境尺度、渺小感 | 开场定世界，或结尾「退回全貌」 | 竖屏信息太稀，别超过 1–2 秒无字 |
| 远景 | Wide / WS | 人物与环境关系 | 建立场景、展示产品使用环境 | 主体太小看不清脸/UI |
| 全景 | Full Shot | 人全身 / 物完整轮廓 | 展示动作流程、身材/产品全貌 | 口播时脸太远，信任感弱 |
| 中景 | Medium / MS | 腰以上，交流感 | 口播、访谈、讲解默认档 | 背景杂则抢主体 |
| 近景 | Close-up / CU | 肩以上，情绪与话 | 金句、反应、产品局部卖点 | 连切多近景易闷、无呼吸 |
| 特写 | Extreme Close-up 偏紧 / ECU 入口 | 细节、材质、表情微变 | 按钮、屏幕显示、眼神、Logo 纹理 | 无动机特写=廉价煽情 |
| 大特写 | Extreme Close-up / ECU | 极致细节、抽象化 | 科技感开场、材质 ASMR 感 | 信息为 0 时别硬拍「酷」 |

**Remotion 对应：** 景别 ≈ 画布内主体占屏比 + 裁切（`scale` + `transformOrigin`）；「切近」= 放大裁切，「拉远」= 缩小露出更多 UI/背景。

---

### 2.2 机位与角度

| 中文名 | 常见英文 | 干什么用 | 短片怎么用一句 | 慎用 |
|--------|----------|----------|----------------|------|
| 平视 | Eye level | 平等、日常、可信 | 口播、产品讲解主角度 | 太平久了无聊，需景别/构图变化 |
| 俯拍 | High angle | 压制、总览、可爱缩小 | 桌面开箱、键盘/电路板总览 | 人脸俯拍显塌，口播少用 |
| 仰拍 | Low angle | 权威、高大、压迫 | 建筑、设备、品牌「力量感」 | 人脸仰拍显胖或滑稽 |
| 侧拍 | Profile / Side | 轮廓、关系、旁观 | 双人对话关系、产品侧面线条 | 口播侧脸难读表情 |
| 过肩 | Over-the-shoulder / OTS | 对话空间、代入一方 | 演示「看屏幕操作」的主观旁观 | 肩占太大挡信息 |
| 主观 | POV | 第一人称代入 | 开箱手部、游戏/App 操作感 | 晃过头易晕；信息要仍可读 |
| 荷兰角 | Dutch angle | 不安、失控、风格化 | 反转、故障、赛博风 1 镜点缀 | 滥用=学生作业感 |

**Remotion 对应：** 俯/仰 ≈ 透视假 UI 或 3D 相机；荷兰角 ≈ 整层 `rotate`；主观 ≈ 光标/手指层 + 屏幕录像式构图。

---

### 2.3 运动

| 中文名 | 常见英文 | 干什么用 | 短片怎么用一句 | 慎用 |
|--------|----------|----------|----------------|------|
| 推 | Push in / Dolly in | 强调、进入情绪 | 说到重点时推向脸/产品 | 无重点乱推；推太慢拖节奏 |
| 拉 | Pull out / Dolly out | 揭示关系、抽离 | 从细节拉出全貌，结尾常用 | 开场就拉=泄劲 |
| 摇 | Pan | 横向扫视空间 | 展台、时间线、对比左右 | 快摇糊；摇完无停顿 |
| 移 | Truck / Tracking | 平行跟随横移 | 跟产品线、跟走动讲解 | 背景跳变干扰 |
| 跟 | Follow | 追随主体 | Vlog 跟拍、演示流程 | 失焦/挡脸 |
| 升 | Crane up / Boom up | 开阔、升华 | 结尾升空感、桌面升到全景 | 短片难真拍，假升要自然 |
| 坠 | Crane down / Boom down | 落入、压迫、落地 | 标题砸入、进入场景 | 与升同理，别炫技 |
| 手持 | Handheld | 真实、紧张、纪实 | 街头、突发、情绪碎 | 抖到看不清字 |
| 稳定器 | Gimbal / Steadicam | 流畅电影感 | 走拍产品、空间漫游 | 「一直在飘」无停点 |
| 希区柯克变焦 | Dolly zoom / Vertigo | 眩晕、认知冲击 | 反转揭晓、数据打脸 1 次 | 用第二次就烂 |
| 环绕 | Orbit / Arc | 立体、炫耀、包围 | 产品 360、角色环绕 | 长环绕=广告片疲劳 |

**Remotion 对应：** 推拉 ≈ `scale`；摇移 ≈ `translateX/Y`；升坠 ≈ `translateY` + 轻微透视；环绕 ≈ 3D rotate 或多层视差；希区柯克 ≈ 放大主体同时缩小背景层（反向 scale）。**一律要有停点：** 动 → 停 → 信息落地。

### 2.4 剪辑节奏

| 中文名 | 常见英文 | 干什么用 | 短片怎么用一句 | 慎用 |
|--------|----------|----------|----------------|------|
| 切 | Cut | 基本换镜、换信息 | 默认手段；一镜一意 | 无理由硬切 |
| 跳切 | Jump cut | 压缩时间、口语感、张力 | 口播去废话；故障风 | 连跳无锚点易乱 |
| 匹配剪 | Match cut | 形/动/色相似衔接 | 圆→Logo、手势→图标 | 硬凑匹配显匠气 |
| L cut | L-cut | 画面先切、声还在 | 解说 Continuity、流畅叙事 | 声画长期错位分心 |
| J cut | J-cut | 声先入、画后跟 | 下一段预告、悬念 | 预告太久观众烦 |
| 蒙太奇 | Montage | 压缩过程、概念并置 | 「从 0 到 1」过程快闪 | 无主题堆镜头 |
| 平行剪辑 | Cross-cutting / Parallel | 两条线交替加压 | 对比 A/B、倒计时双线 | 线太多跟丢 |
| 留白 | Hold / Beat / Negative time | 让观众消化、情绪着地 | 金句后停 0.3–0.8s | 留白过长=空 |

**Remotion 对应：** `Sequence`/`Series` 控切；`spring` 阻尼=「停点」；stagger=蒙太奇里的错峰；匹配剪=共享形状/色 token 跨段；L/J ≈ 音频轨与视频轨 offset。

### 2.5 构图

| 中文名 | 常见英文 | 干什么用 | 短片怎么用一句 | 慎用 |
|--------|----------|----------|----------------|------|
| 三分法 | Rule of thirds | 稳、可读、留呼吸 | 人脸放左/右三分线；竖屏靠上 1/3 | 每镜死磕三分反而僵 |
| 中心构图 | Centered | 权威、仪式、产品英雄 | Logo、产品正面、标题锤 | 全程中心=PPT |
| 引导线 | Leading lines | 眼随线走 | 桌沿、建筑线指向主体 | 线指向空处 |
| 前景遮挡 | Foreground framing | 纵深、偷窥感、层次 | 虚化前景框住主体 | 挡关键信息 |
| 景深/虚实 | Depth of field / Bokeh | 分离主体、电影感 | 口播虚背景；产品实、背景虚 | 虚过头细节没了 |
| 负空间 | Negative space | 呼吸、高级、字好放 | 一侧空给字幕/金句 | 空太大信息稀 |

**Remotion 对应：** 三分/中心=布局 grid；引导线=几何装饰指向；前景遮挡=半透明 UI 层；景深=模糊层/阴影分离；负空间=字周围 padding，别贴边。

### 2.6 光色（短片够用）

| 中文名 | 常见英文 | 干什么用 | 短片怎么用一句 | 慎用 |
|--------|----------|----------|----------------|------|
| 三点光概念 | Key / Fill / Back | 主体立体、从背景分离 | 主光定形，辅光降死黑，轮廓光抠边 | 三灯全开一样亮=平 |
| 侧逆光 | Side-back / Rim | 轮廓、质感、氛围 | 科技产品边缘光、人物剪影感 | 脸全黑则需补一点辅光 |
| 色温对比 | Warm-cool contrast | 情绪分区、时间感 | 暖主冷背景，或冷科技+暖人 | 乱调色无语义 |
| 高调 | High-key | 明亮、干净、轻快 | 美妆、清新、白天感品牌 | 易过曝丢层次 |
| 低调 | Low-key | 神秘、高级、戏剧 | 夜景科技、悬念开场 | 暗到字幕不可读 |

**Remotion 对应：** 三点光 ≈ 主体亮、背景暗、描边/外发光当轮廓光；色温对比 ≈ 背景色与字色/强调色对立；高调低调 ≈ 整体亮度与对比 token。

### 2.7 声音

| 中文名 | 常见英文 | 干什么用 | 短片怎么用一句 | 慎用 |
|--------|----------|----------|----------------|------|
| 同期声 | Sync / Diegetic | 真实、在场 | 开箱撕膜、键盘声增强可信 | 嘈杂盖过人声 |
| 画外音 | VO / Voice-over | 信息承载、叙事 | 知识口播、解说 B-roll | VO 与字幕抢读 |
| 音乐卡点 | Hit / Beat sync | 节奏锚、爽感 | 切镜/字锤落在鼓点 | 每镜都卡=机械 |
| 静音停顿 | Silence / Mute beat | 强调、反差、消化 | 抛问题后静 0.5s 再答 | 静太久以为卡了 |

**Remotion 对应：** `Audio` 轨对齐 frame；卡点用 beat 时间表驱动 `Sequence`；静音=主动去掉 BGM 一两拍，比一直小声更狠。

## 3. 「导演现场口令」式速查：短片配方

格式：**开场前 3 秒 → 信息段 → 高潮 → 结尾**。每套可直接套用；括号内 = Remotion/动效等价。

---

### 配方 A｜产品讲解（开箱 / 功能演示）

| 段落 | 手法组合 | 口令 |
|------|----------|------|
| 前 3 秒 | 特写材质或屏幕亮起 + 同期声（撕膜/开机）+ 一句利益点字幕 | 「先给爽点，别先自我介绍」 |
| 信息段 | 中景口播平视 ↔ 插入近景操作；J-cut 提前入下一段 VO | 「一镜一卖点，卖点落地再切」 |
| 高潮 | 推近到核心功能 UI + 音乐卡点 + 字锤数字/结果 | 「唯一一次大力推，推完停」 |
| 结尾 | 拉出全貌产品 + 负空间放 CTA；静音半拍再出关注引导 | 「停一下再要关注」 |

**动效等价：** 特写=`scale` 裁切；推近=spring scale；字锤=大号字 + 短 spring；CTA=负空间 + 按钮入场 stagger。

---

### 配方 B｜科技热点（快评 / 播报感）

| 段落 | 手法组合 | 口令 |
|------|----------|------|
| 前 3 秒 | 跳切新闻图/截图 3 刀 + 大标题砸入 + 高能 BGM 入点 | 「标题即钩子，3 刀内抛完事件」 |
| 信息段 | 中心构图口播 + 右/下三分放要点列表 stagger；L-cut 保语流 | 「嘴不停，字分条出」 |
| 高潮 | 平行剪辑：观点 A ↔ 数据/对比图；一次荷兰角或色温对打 | 「对比要狠，手法只用一次异样」 |
| 结尾 | 一句话立场 + 留白 0.5s + 互动提问字幕 | 「立场落地，把评论权交给观众」 |

**动效等价：** 跳切=短 `Sequence`；列表 stagger；对比=左右 split + 色 token 对立。

---

### 配方 C｜知识口播（干货 / 教程结构）

| 段落 | 手法组合 | 口令 |
|------|----------|------|
| 前 3 秒 | 痛点提问（近景）+ 静音停顿 + 「今天只讲 3 点」字幕 | 「问题→停→目录，立刻建立契约」 |
| 信息段 | 平视中景为主；每点：切 B-roll 全/中景演示 → 回脸总结；匹配剪衔接概念 | 「脸讲结构，手给证据」 |
| 高潮 | 最难那点：推近 + 图解全屏（虚实分离主体）+ 音乐略抬 | 「难点配最大画面」 |
| 结尾 | 三点回顾字卡（中心）+ 轻拉或缩小露出关注区 | 「复述目录=记忆钉」 |

**动效等价：** 目录=编号 stagger；图解=全屏 diagram Sequence；回顾=三卡再播一遍短版。

---

### 配方 D｜品牌氛围（形象 / 调性片）

| 段落 | 手法组合 | 口令 |
|------|----------|------|
| 前 3 秒 | 低调侧逆光大远/远景 + 几乎无字 + 强 BGM 起势 | 「先感觉，后信息」 |
| 信息段 | 环绕或稳定器慢移 + 高品质特写材质交错；字少、字大 | 「少字大字，靠光色说话」 |
| 高潮 | 希区柯克或猛推一次到 Logo/产品英雄中心构图 | 「仪式感只给一次」 |
| 结尾 | 升/拉出负空间 + Logo 静持 1s（可超短片常规） | 「Logo 要站得住，别闪就走」 |

**动效等价：** 慢移=长 duration 缓动；字锤少而大；Logo 静持=`freeze` 或长 hold。

---

### 配方 E｜数据/对比叙事（适合 Remotion 数据片）

| 段落 | 手法组合 | 口令 |
|------|----------|------|
| 前 3 秒 | 一个惊人数字字锤 + 短静音 + 再出单位/语境 | 「数字先砸，语境后补」 |
| 信息段 | 图表逐元素 stagger；引导线/高亮指向当前读点；口播或字幕二选一主通道 | 「同一时刻只让人读一个数」 |
| 高潮 | 前后对比并置（平行）或 race 冲线卡点 | 「对比帧要对齐，才能懂」 |
| 结尾 | 结论一句 + 图表缩回负空间给 CTA | 「结论>图表，图表退居背景」 |

**动效等价：** 数字滚动 + stagger 系列；高亮=`opacity`/`stroke` 强调当前系列。

---

### 配方 F｜UI/产品界面卷轴（SpecStory 类英雄片）

| 段落 | 手法组合 | 口令 |
|------|----------|------|
| 前 3 秒 | 假 UI 中心构图快速 scale 入 + 光标 POV 点一下 | 「先像真产品，再讲理念」 |
| 信息段 | 跟焦式 pan/scale 游走界面；每停一处出一句功能字幕 | 「游走有停点，停点即卖点」 |
| 高潮 | 多窗口 stagger 弹出或 Bezier 大缩放穿过界面 | 「一层层打开，别同时炸」 |
| 结尾 | 拉远露出完整产品窗 + Logo/口号居中 hold | 「从细节回到产品全貌」 |

**动效等价：** 几乎全是 Remotion 主场——`scale`/`translate`/`stagger`/`spring`；实拍可插真人反应近景作「信任钉」。

## 4. Remotion / 动效对应表

| 实拍手法 | 代码片等价（概念） | 注意 |
|----------|-------------------|------|
| 推 / 拉 | `scale` 放大/缩小 + 定 `transformOrigin` | 推完要 hold，别线性来回搓 |
| 摇 / 移 | `translateX` / `translateY` | 竖屏少做大横摇 |
| 升 / 坠 | `translateY` ± 轻微透视/阴影变化 | 配 easing，别匀速电梯 |
| 跟拍 | 主体层不动、背景视差反方向动 | 视差过大易晕 |
| 环绕 | 3D `rotateY` 或多层不同速平移 | 短片 90–180° 够 |
| 希区柯克变焦 | 前景 scale↑ + 背景 scale↓（反向） | 一次足够 |
| 切 | `Sequence` 硬切；或 opacity 0 帧切换 | 短片默认硬切比溶解干净 |
| 跳切 | 同构图短 Sequence 连续切 | 配音要接得上 |
| 匹配剪 | 跨段共享形状/色/运动方向 token | 在 `tokens` 里锁死 |
| 蒙太奇 | 多段短 Sequence + 统一转场 | 要有主题句串起来 |
| 平行剪辑 | 左右分屏或 A/B 交替 Sequence | 标清「谁在左」 |
| 留白 / 停点 | `spring` 落地后多持有 N 帧 | 动效最怕「永不歇」 |
| 字锤 | 大字 + 短 spring / 过冲；可配 hit 音 | 字锤=特写，滥用同罪 |
| 列表/多元素入场 | `stagger` 延迟 | 方向与阅读顺序一致 |
| 景深虚实 | 背景 `blur` + 主体清晰；或阴影分层 | 虚到字不可读=失败 |
| 三点光分离 | 亮主体 / 暗底 / 描边或外发光 | 对比度服务可读 |
| 色温对比 | 背景色 vs 强调色对立 token | 全局色板先定再动效 |
| 音乐卡点 | beat 时间表驱动切镜与字入点 | 先锁音频再写动画帧 |
| 静音停顿 | 特定段 `volume=0` 或去掉 BGM | 比一直 duck 更有戏剧性 |
| 主观/光标 | 光标层 + 点击波纹 + 屏幕内容响应 | 光标别挡字 |
| 荷兰角 | 整合成层小角度 `rotate` | ≤8–12°，短促 |

**参数化提醒（对接你现有 Remotion 拆镜习惯）：** 节奏写入 beats/tokens；字色与背景对比先锁；能 props 化的（标题、数字、色板）不要写死——和 Unwrapped / 活动片同一逻辑。

## 5. 常见业余坑

| 坑 | 为什么糟 | 改法（一句） |
|----|----------|--------------|
| **乱用特写** | 无落点的特写只剩「好像很电影」 | 特写必须对应一句信息或一次情绪；否则回中景 |
| **无动机运镜** | 观众不知道该看啥，只觉晃 | 先写「这一镜看完观众应得到 X」，再决定推/拉/摇 |
| **信息没落点** | 好看但记不住，完播无转化 | 每段结尾用字卡/口播复述那一句；Remotion 则 hold 结论帧 |
| **BGM 盖过人声** | 信息主通道被抢，尤其手机外放 | 口播段 duck BGM；金句可静音；永远先听人声是否清晰 |
| **每镜都在动** | 无停点=无记忆点；动效片尤甚 | 动→停→信息；spring 落地后强制持有；实拍同理「推完别立刻下一切」 |
| **竖屏当横屏拍** | 头顶脚底大片空、主体过小 | 按竖屏重构图：脸靠上、字避手势区、少用大远景 |
| **字幕与口播不同步/重复抢读** | 认知双通道冲突 | 字幕=关键词，不要整段逐字跟读；或静音纯字幕二选一 |
| **转场炫技** | 注意力去了转场本身 | 短片默认硬切；花式转场最多 1 次且有语义 |
| **开场先自我介绍** | 前 3 秒流失 | 利益点/冲突/数字先上，身份后补或不补 |
| **结尾闪完就没** | 情绪与 CTA 落空 | 结尾 hold：Logo/结论/行动指令至少 0.8–1.5s |
