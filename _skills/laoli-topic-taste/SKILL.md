## 他怎么选（机制）
1. 主要读**小时报**，不只读晨汇总勾选表。
2. 下达方式多为**短指令批量清单**（「三个都做」「做A短片，再做B图文实测」），很少「加池 N」精挑。
3. **快播门槛低于图文**：有刷屏画面就能点短片；图文要能进现有栈或能系列跟做。
4. 图文常**系列化扫货**（WorkBuddy 12 场景、DSH 办公/财经选题卡全选），不是每天散点一个陌生开源。

## 快播（TVP）命中信号
抬这些（有实拍/官方 demo 优先）：
- 大厂发版或新产品，且已有官方/作者 demo 视频在刷（成片例：Kling 4.0 官方 Creator Highlights）
- 强视觉硬件/出行/机器人路测或产品实拍（小时报常跟 Cybertruck→Cybercab / Robotaxi 一眼续；Roadster 类 brief 目录存在）
- 安全/合规翻车且有画面或强反差（小时报软去重：高盛限/收回 Claude Code；Claude Code Open VSX 投毒）
- 科技圈名人反差新闻（有新闻画面/股价走势可成片；八卦口吻要克制；例：黄仁勋相关续炒——具体窗曾标「勿开稿」也要听当日指令）
- 传闻发版但已在做 TVP 的旁观片（例：Fable 已在做 TVP#55 传闻锁）

快播**可点、图文不一定点**：猎奇视觉、传闻发版旁观片、本人跑不通的模型发版拆解。

## 图文实测命中信号
抬这些：
- **现有工作流可插**：出片/旁白/MCP/agent 开源（FilmCraft、HyperFrames、OpenDesign、Kokoro、video2ctx、Caveman、Magpie 系——池内多为 Justin 点名 done）
- **办公 Agent 场景包**：WorkBuddy / DSH 一类「今晚抄进桌面」跟做，可系列连开（catcher-73～86、12 场景包）
- **白嫖/省钱真办事**：免费云主机、额度羊毛（诚实写国行/风控边界；例：Simular catcher-92、千问 Go 云电脑小时报）
- 大厂开源若能装/能截最小 demo（如 Meta Astryx catcher-91），可旁观实测；无 Claude 订阅则禁止第一人称「我跑通了」

## 降权（历史很少点或长期 backlog）
- 晨汇总里「①优先」但无画面、无跟做路径的空壳
- 纯观点、缺资源硬写「我跑通了」（E 类：Argon / Claude skill）
- 币圈/财报硬新闻（除非强视觉或供应链办公可跟做；Binance 类多进安全叙事而非跟做）
- 与已成稿同题复读
- 门槛高：企微企业号、不稳 Browser Use Beta（F 类长期 backlog）

## 自动开做
触发：工作日早间例行，或用户说找选题/开做今日选题。
1. 扫近 12–24h 捕手小时报 + 晨汇总 + 池内 A/B/C backlog/ready；对照 `TRAINING_TOPICS.md` / `BLOGGERS.md`。
2. 按上表打分；列出命中项与建议产物（快播 / 图文 / 双线）。
3. 默认自动开：**至多 2–3 支快播**（有真画面才开）+ **至多 1 篇图文**（守约每天约 2 篇成稿节奏；系列日可按用户历史批量上调但要说清）。
4. 派 TVP / 科技图文工坊 / 花叔16∶9；更新池状态；成稿交评审，不代发。
5. 无命中只报「今日无强匹配」，不硬凑。
